# CELESTIAL HALO-9

**Minecraft Java向けの大規模SF都市・建築研究プロジェクト / A monumental science-fiction Minecraft city design research project.**

巨大なリング構造と16の個性的な建築施設を中心に、光に満ちた公共建築、重厚な暗色の機械構造、広大な空中広場、多層の歩行者空間を設計しています。

The vision combines a vast orbital ring, sixteen distinct sites, luminous civic monuments, dark industrial supports, monumental voids, and layered public circulation.

## 開発状況 / Project status

- **設計・3D可視化・非施工の検証が中心です。** 実Minecraftワールドを建築・改造する公開用ツールではありません。
- **比較用の既存基準は M101 `TERRACED_DISTRICT_RIM`。** M118以降の都市案・内部造形案は研究候補であり、正式採用された都市設計ではありません。
- **Minecraftへの施工は HOLD。** 正式な施工ワールドは未登録で、保護構造、予約空洞、道路・公園、歩行可能性、正確な座標系の確認は未完了です。
- **`main` は案内用の初期ブランチです。** 後続の設計・検証コードの多くは、未マージのDraft PRと研究ブランチにあります。`main`に存在するものと誤認しないでください。

## 安全な開発 / Safety

このリポジトリの設計候補を、既存のMinecraftワールドへ無断で反映しないでください。Freeze・既存保護建築・公共アクセスなどの変更、施工先の指定、正式設計の採用には別途明示的な承認が必要です。GitHub Actionsは読み取り専用の方針検査・オフラインテスト用です。

No proposal in this repository authorizes live Minecraft-world writes, automatic merges, protected-geometry changes, or promotion to an approved build.
