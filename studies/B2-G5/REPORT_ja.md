研究座標はX＝東、Y＝北、Z＝基準地盤からの高さ。X/Y各−5〜+5km。比較用中央領域は約4km四方。地形の実標高・既定都市中心との誤差は未測定。人工地盤は原地形を全面被覆せず、地上の街路網を残して複数の乗換口で接続する。

都市圏交通は地上の東西・南北公共交通を基礎とし、中心部に入る前に三つの外縁乗換口（研究上の仮称：東口・北口・西口）へ分配。単一中心駅への集中は避ける。既存都市軸を新しい主質量で塞ぐ位置には据えない。軸と景観回廊の実線形が得られるまでは図の点線は方向のみを示す。

三大都市軸は既定線形を保持する条件とし、本研究では便宜上「既存軸①〜③」と呼ぶ。名称・方位・交点を確定しない。G5-01は軸が中央に入る地点を横断公共ホールの開放部へ対応させ、軸ごとに地上通過と高度乗換の二つの選択肢を残す。G5-02は軸の上に支持体を置かず、編まれた地盤の隙間または下面の開放回廊へ対応させる。どちらも全軸を一つの中央駅へ曲げない。景観回廊は単なる交通路とせず、主要眺望の抜けを留保し、建築外形側を調整する。V1〜V3は未同定の既存要素として個別に保護条件へ登録し、中央との接続可否も未確定とする。

## 3｜G5-01《昇街褶都》— 地表から育つ公共建築の連鎖

### 形成規則と主質量

最初に三本の幅広い公共街路を考える。それぞれがホールの屋根へ移り、屋根上に水平な生活地区が開き、その地区の端が次の公共建築を包む。三本は同じ山へ収束せず、途中で異なる高さに分岐・再接続する。**生活地盤は水平、連結部は斜行交通、包絡面は曲面**として役割を分ける。全体を一本の巨大な歩道坂にしない。

主質量の研究上の包絡寸法は東西3,800m×南北4,200m×頂部2,800m。これは実モデルの実測でない。南から北へ上昇する三つの折れた都市帯と、異なる高さの横断公共ホールが一体のシルエットをつくる。中央に一枚の山体や閉じた環状壁は置かず、街路の下が建築、建築の上が次の街路になる断面の反復が外形を決める。

### 人工断崖の厚みを都市にする

外部から内部への順序は「前庭→店と入口→中庭街路→居住の入口→設備・構造帯」。居住は外気に面する外縁・中庭縁に限り、計画上の奥行12〜24mを目安とする。巨大床全体を厚い住宅壁にしない。主生活層の高さ60〜120mごとに空へ通じる横断切欠きを設け、その間を通常規模の複数階が埋める。構造帯には住宅窓を貼らず、保守・循環・避難区画を与える。

三本の都市帯の間は幅180〜360mを検討する光の街路。全高の深い峡谷へ光が届くとの保証はないため、縦穴だけで採光を解決しない。横断切欠き、浅い居住縁、低層の地上への開口、北側の背面出口が必要。風・日射・排煙の解析前に人口や床面積の成立を宣言しない。

## 4｜G5-02《天架織都》— 高空地盤が都市を組織する

### 形成規則と主質量

地表を盛り上げるのではなく、まず高度の異なる二本の長大な共有地盤を交差させる。交差部を巨大公共建築とし、その地盤が六つの中空の都市支持体へ折れ込んで地上へ降りる。支持体は柱の外に窓を貼るものではなく、光庭を囲む住居・学校・駅の立体街区。大地は一枚の板でなく、幅広い帯が接合部で幅を増し、採光の隙間を挟んで編まれる。

研究包絡は東西4,600m×南北3,600m×頂部2,600m。主地盤はZ1,450mと2,200m、厚さ120〜220mを仮定。幅400〜700mの都市帯が織り合う。六支持体の外径相当は400〜650m、内部光庭の幅160〜260m。支持体間の無支持距離は最大約1.2kmを研究仮定とするが、構造能力を示す数字ではない。六支持体は新案内部のS1〜S6であり、既存H1〜H6とは別物。

### 主要断面と公共生活

Z−180mの物流→Z0地上街路→Z300/700/1,100mの支持体内部の地域街路→Z1,450mの下部都市地盤→Z2,200mの上部都市地盤→Z2,600mの環境・観測終端。上下都市は交差部でつながるが、全移動を交差部へ集中させず、各支持体に複数の縦交通を持たせる。

交差部の《空の共同庁》は平面800×500m、有効高さ180mを検討する巨大公共街区。図書館・議場・市場は中央の空間へ面し、屋根上は次の都市の公園・通学路となる。単体の屋上神殿にはしない。300×200×140m級の医療・文化複合体は帯の節で地盤に組み込み、24〜48m程度の生活建築の群と同時に見せる。

支持体内部は中庭街路を外周街路と60〜120m高度ごとの水平切欠きで接続。住居の奥行は12〜24mを計画目標とし、光庭を全高の暗い井戸にしない。ただし地下都市の先例は採光の証明ではなく、内部化という空間操作の参照である。地盤下の地上は北・東へ抜ける広場と交通、南西への開放空間を優先し、暗い残余地を住宅で埋めない。

G5-01との違いは、地区と主地盤の成立順、荷重と交通の集中場所、地上から上空への体験にある。G5-01は屋根・内部・街路を何度も往復しながら都市の高度が変わる。G5-02は縦の都市を通って別の大地へ到達し、その上を横へ暮らす。曲率や穴の数の違いではない。

| 視点 | 景観構想と審査ポイント |
|---|---|
| 正面＝南 | 途切れを持つ二つの高空地盤が一つの文明の地平をつくる。大皿や駐車場デッキに見えれば失格 |
| 斜視＝南東 | 地盤の交差、屋根下の公共街区、支持体内部の明るい庭が同時に見える |
| 側面＝東 | 1,450／2,200mの二地盤と縦都市が読め、自然の内海に空が残る |
| 背面＝北 | 六支持体の背面も生活の入口を持ち、高空地盤端に学校・公園が現れる |
| 俯瞰 | 帯の編み目、水平街区、光の切れ目が見え、巨大一枚床へ還元されない |
| 内部＝支持体Z700m | 中庭を渡る地域街路、学校と駅、上部地盤の裂け目から来る光。無機質な巨大柱内部にしない |

神聖さは頭上にもう一つの大地がある静謐さ、危険さは露出した接合部と都市地盤の切断面で表現。巨大スパンの工学的裏付けがない現段階では、G5-01より演出と構造の乖離が大きい。

## 6｜美術比較と失敗への診断

これは作者による構想審査。数値点を付けて実測のように扱わない。

| 評価 | G5-01 昇街褶都 | G5-02 天架織都 |
|---|---|---|
| 遠景の唯一性 | 折れた都市街路の連鎖が一つの上昇する地形になる可能性。山のシルエットへ戻る危険 | 二重の人工地平は強い。巨大板・橋の集合へ還元される危険 |
| 接近時に都市が現れる | 屋根下の市場と屋根上の街区が連続して見えるため、今回の主条件への説明力が高い | 縦都市の内部は強いが、高所到達まで日常が見えにくい |
| 外部／内部／高所の連続 | 三者を何度も往復する生活経路が形成原理そのもの | 縦都市と横都市の節で成立。昇降依存が大きい |
| W0との関係 | 地上の入口を分配し、海・断崖・負空間を中央の資材にしない | 大地の下に空間を残せるが広い影と風の問題が大きい |
| 背面 | 北側の出口・学校・居住街区が必須。美しい表の背後を壁にしない | 支持体背面と地盤下面の公共性が弱点 |
| 神聖80／危険20 | 光の都市面と暗い構造の奥行の対比。住む場所が主役になる | 空の大地が神話的。構造の誇示が危険側へ偏る恐れ |
| 発明性 | 公共建築の断面を増殖単位にして都市地形をつくる | 都市を支える地盤と、その地盤を支える都市が相互生成する |
| 暫定判定 | **優先して中央監督の構想選抜へ提出** | **独立対案として保持** |

旧失敗の検討：巨大水盤の問題に対して、水の有無ではなく公共生活が主質量を生むかを問う。G5-01に高所水盤はないが、それ自体は成功条件でない。山塊寄せ集めに対しては各折れの中に実際の街路・上下の公共用途が読める必要がある。厚い壁に対しては住居を浅い縁と中庭へ分配し、横断切欠きが外部へ抜ける必要がある。G5-02も一枚の厚い床と巨大柱に還元されれば同じ失敗を別方向に繰り返す。

## 7｜暫定選抜と次の審査条件

G5-01を暫定有望案とする理由は、高所に完成品の街を置く発想を越え、**下の公共建築と上の生活地盤が同じ断面の表裏になり、日常生活の経路が外形を決定する**点。G5-02は巨大人工地平という別の文明像を保持する。ただし両案とも図面段階であり、美術合格の判定は中央監督に留保する。

中央監督がG5-01を選んだ場合の最初の実3Dは、全都市の精密化ではなくP1→P2→P3の一連の断面を含む低詳細の検証とする（現時点では実施しない）。遠景5方向とP2内部、P4高所で「道路・ホール・地区の連鎖」「背面の生活」「巨大壁への退行なし」を確認する。G5-02選抜時は交差街区と一支持体の中庭・地上・高所の関係を優先する。

次工程ゲート：①W0・全端点・保護空間との整合、②中央監督による二案の構想選抜、③低詳細3Dの外部／内部美術審査、④構造・採光・風・避難・交通の検討、⑤承認後のみ精密化。今回完了したのは二案の構想資料と自己比較まで。①は資料未確認、②以降は未実施。施工HOLD、正式M247-C保護、Work利用は事前承認制を維持する。
