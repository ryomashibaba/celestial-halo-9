# B2-G7 — 異なる二つの都市地形の発生仮説

2026-10-23 JST／B／art/b／基準 6da74b479bae8250739fe9fc413e513b94e243fd

比較の問いは「公共ホールを積んだ門」からどう離れるか。既存G6のメッシュ・輪郭・屋根反復は使用しない。歴史建築の外観は参照せず、G5で整理した高度別生活組織、内部街路の厚み、地面と公共建築の連続という研究上の原理だけを再検討した。今回は新たな先例調査を行っていない。

| 比較項目 | A《街胞断層》 | B《合流地盤》 |
|---|---|---|
| 最初に生まれるもの | 両側に生活の奥行を持つ、外気に開いた街路細胞 | 異なる到着地を結ぶ、厚みを持つ複数の交通・都市帯 |
| 成長操作 | 街路の側方へ公共・居住区を増殖。隣接地区との高度差で側面と肩の広場を発生させる | 都市帯の合流部を水平公共地盤へ広げる。合流の移動が支持都市・輪郭・上空地区を変える |
| 地形ができる理由 | 既成の山を削るのでなく、街路の両縁の都市体積が隣の地区の崖面となる | 山体に道路を載せるのでなく、移動のネットワーク自体を厚い都市体積へ変える |
| 公共建築 | 街路端の厚い交差部に公共複合体を持つ。全体を一つの大ホールにしない | 合流部の下層を公共複合体、上面を駅前と学校・市場を含む水平地区とする |
| 内部街路 | 各細胞の幅110mの開放スロット、76mの地上街路帯、後端の二系統縦交通の仮設包絡 | 帯の中の交通・物流と、支持都市の縦交通、水平な合流地区を分ける |
| 高高度都市 | 肩と後端地盤を複数高度でつなぐ。頂上の展望台だけにしない | 8つの水平合流地区を広域の生活拠点とする。斜面上に住宅を貼らない |
| 外形の変化の仮説 | 街路の延長と地区の増殖が平面の枝分かれ・高さのずれ・共有地盤の位置を同時に変える | 到着地の増減が帯の分岐と合流点を変え、地区・支持都市の位置が変わる |
| 最も大きい失敗リスク | 街胞が巨大箱になり、上の地盤が余った屋根にしか見えない | 合流地盤が橋の踊り場になり、都市が高架構造の添え物になる |

これらは設計仮説。需要・人口を入力した成長シミュレーションを実装したものではない。生成コードは一つの静的な構成例を作る。

## 10km都市との関係

研究座標はX東・Y北・Z上、比較用の10km正方形の中央に配置する。Aの建築外接寸法は約3.05×2.76×1.98km、Bは約4.06×4.01×2.18km。周囲の低いタイルは都市域を読むための仮設目盛であり、既存建物ではない。`context.jpg`に10km全体を記録した。

両案とも地上の複数方向から高度交通に分散乗換する構想とし、一個の中央門へ集約しない。北高原と西断崖への基礎固定、東内海の水際改変、南西負空間への張り出しは保留する。三大都市軸・景観回廊・V1〜V3・H1〜H6・SB01〜16・HERO4は既存条件として保持するが、現行確定座標が未確認のため具体的接続・重ね合わせ・変換行列を作らない。10km域に収まることは正式配置への適合を意味しない。

## 高高度都市を単なる屋上にしない条件

AはZ1,000m以上に合計約3.19km²、Bは約3.07km²の模式水平地盤を持つ。これは地盤メッシュの面積総和で、接合や重なりを控除した可用面積、人口収容力、建築延床面積ではない。Aの最高水平地盤はZ1,940m、BはZ2,160m。モデル外接最高点は交通帯等を含むため異なる。

両案の生活プログラムは、居住・学校・診療・食と市場・地域文化・運動庭・日用品物流を同じ高度地区に持たせ、地上へ毎日降りなくても生活できること。主街路16〜24m、中庭と外気に面する浅い居住帯、徒歩圏ごとの広場、独立した複数の高度交通を検討単位とする。Aは各街胞に地区単位の公共サービス、Bは各合流地盤に地区拠点を置く構想である。

初期審査で不合格になったため、これらの室・住居・路地・避難経路は制作していない。「本格的な高高度都市が実3Dで成立した」とは判定しない。必要な都市プログラムを定めたうえで、それを育てられる主構成かを先に審査した。
