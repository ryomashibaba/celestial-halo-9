# CELESTIAL HALO-9 — C2-G5

2026-10-23 JST / 独立研究C / art/c / CONCEPT

**暫定有望案はA《天衢会都／会流宮》。都市の三大軸を一つの直線へ収束させず、公共施設へ通う複数の流れが中央で太くなり、異なる高さの公共室を生む。B《六庭共議都／交響公館》は、分散する公共活動の交換を外形へ変換する対案として保持する。両案とも中央監督未審査・美術採択HOLD。**

## 2. 実在4先例：原理の抽出

### C1 Brasília — 都市の尺度を一つの秩序に置く

UNESCOは記念性・居住・社会的活動・緑地という四尺度と、記念軸・交通軸・住区・公共建築の対応を説明する。抽出するのは巨大な軸だけでなく、日常と象徴の尺度を相互に位置づける仕組み。HALO-9では生活街路→地区広場→広域公共室→都市の負空間という尺度の接続に翻訳する。住宅を遠い背景へ追いやらず、公共施設の入口に日常の目的地を置く。形の対称性や鳥形平面は継承しない。[UNESCO](https://whc.unesco.org/en/list/445)

### C2 Teotihuacan — 建物間の空間が接近体験をつくる

指定されたINAHページは本文取得が502となった。公式ページの検索索引では、地盤の変化・広場・側方の基壇・近づくにつれて大きくなる月のピラミッドを確認できた。INAHの別資料も都市軸と周囲の山地の関係を述べる。抽出するのは「建物間の余白と景観の奥行きが、歩行の時間に沿って象徴を立ち上げる」原理。階段ピラミッド、特定の方位、歴史上の儀礼の再現は行わない。軸長などの数値は今回の根拠に使わない。[指定INAHページ](https://visitateotihuacan.inah.gob.mx/en/explore/avenue-of-the-dead/)、[INAH都市史](https://www.inah.gob.mx/boletines/historia-breve-de-teotihuacan)

### C3 CCTV Headquarters — 活動の隣接が三次元の外形になる

OMAは通常の高層塔への代案と、視点によって変化する建築像を説明する。共同設計者Ole Scheerenの一次資料は制作・管理・放送などを連続する活動として結ぶ構成を説明する。HALO-9では公共活動間の隣接・移動・共有空間から断面を決める。閉じたループを作ることは要件にしない。業務施設の循環をそのまま都市全員の動線へ拡大することも避ける。[OMA](https://www.oma.com/projects/cctv-headquarters)、[Büro Ole Scheeren](https://buro-os.com/projects/cctv)

事業者の一次資料は分棟、SkyPark、博物館・劇場・展示等と相互につながる公共空間を紹介する。抽出するのは、別々の施設の上に新しい共通目的地を持たせ、都市像をつくる原理。HALO-9では異なる高さの公共の肩・屋上庭を共有する。三本塔と船形の上部床は写さない。ホテルの有料・宿泊者用領域を、無条件に開かれた公共空間の実例とも扱わない。[Marina Bay Sands](https://www.marinabaysands.com/guides/exceptional-experiences/marina-bay-sands-architecture.html)

## 3. 全都市に共通する設計条件

遠方約10kmの視点を最初の判定位置とする。外周生活都市の細かな粒度、空中地区の中尺度、中央公共建築の巨大質量、W0の大きな空白を同時に読む都市像を目標とする。中央だけを巨大化して周囲を添景にしない。

三大軸には、既存の役割を確認後に、式典の接近、日常の都市間移動、知と文化の往来という体験上の層を重ねる。これは軸の改名・用途変更ではなく設計の評価軸である。V1〜V3には、それぞれ連続して残す見通し、側方の施設が段階的に現れる見通し、上下の都市関係を読む見通しを割り当てられるか検討する。番号との対応は保留する。

W0は新しい宮殿のための埋立地にしない。中央HALO-9の既存輪郭とCELESTIAL SPINEの予約領域を、追加形状より先に照合する。図ではHALO-9のリングを再設計しておらず、正確な占有を描いていない。SPINEは既存幹線との接続条件として扱い、その上に巨大な梁を新設する理由にはしない。

地上・中高度・高高度の区分と提案寸法は、**新設部分を比較するためのローカル設計値**。MinecraftのY、既存Hの標高、実測値ではない。居住人口・延床面積・輸送能力は未算定。

## 4. 案A《天衢会都／会流宮》— 接近の流れが公共建築の厚みになる

文明思想：都市の中心とは、統治者の単独の頂点でなく、各地区の人々が異なる用事を持ったまま同じ空間に居合わせる「共在の場所」である。

### 都市構成・中央の外形

10km都市の三方向から来る軸を、中央直前で三つの異なる深さの公共前庭へほどく。前庭は一本道の終点ではなく、横断する生活街路と接する。中央には、長さも厚さも異なる**四つの公共街区が互いに食い込み、上へ向かうほど片側へ厚みを移す一棟**を置く。四つはHERO4の移築体ではなく、各施設の活動を受け取る中央側の公共室群である。

外形は、低い厚い到着街区、中央で高く膨らむ会合街区、深い採光裂隙、片側へ伸びる生活街区の肩からなる。不等高・不等奥行の凸部と切込みが正面・側面で異なる。上部を一本の床で結ばず、屋根を連続した器にもせず、地上から立つ幅広い街区の側面を見せる。提案外接域は約2.8×2.1km、最高約2.2km。外形寸法は比較用仮説で、W0との実配置照合を通していない。

主質量の幅約350〜650mの帯は、丸ごと深い無採光床にしない。40〜80m程度の占有帯と縦の中庭・公共室・設備帯へ分節する設計方針。後者の幅・採光・支持方法は未検証。輪郭全体を階段状に縮小せず、張り出す厚い側面と縦の光の切込みで都市の活動を示す。

### 公共施設が形を生む因果

| 既存施設との関係仮説 | 中央に新設する受け手 | 外形・広場が変わる理由 |
|---|---|---|
| SB05の大身廊へ向かう／そこから戻る流れ | 地上から中高度へ続く集会前室群 | 大人数が滞留する厚い低層の肩が必要。なくすと主役の低く長い側面も縮む |
| SB08の二つの巨大内部空間との往来 | 二つの異なる高さの公共室と、その間の採光裂隙 | 同じ高さへ均すことができず、中央輪郭に深い切込みが生まれる |
| SB09の保護された閾を経る接近 | 無屋根の通過前庭と側方の到着街区 | 門を中央へ再製せず、門の先に空が残る。前庭の余白が一方の質量を後退させる |
| SB12の聖域・眺望との対話 | 最上部の静かな公共庭と小規模滞在施設 | 主屋根が一様に広がらず、片側だけ高く厚い肩を持つ |

HERO4の中心性は、中央より小さい建物であることから決まらない。SB09は都市への閾、SB05とSB08は大量の人が集まる独立した目的地、SB12は中心を離れて都市全体を見る場所となる。中央はその四つの体験の共有部を引き受ける。所在地・高度・現在の用途が確認できた時点で、この仮説を訂正する。

### 断面と生活

| 新設部分の提案高度 | 空間と用途 | 交通・生活との関係 |
|---|---|---|
| 地上〜約250m | 到着街区、屋外前庭、案内・市・日常サービス、下部公共室 | 広域交通は前庭の側方に停まり、通過客と滞在客を分ける。物流は別系統 |
| 約250〜900m | 集会・文化交流の公共室、複数の屋上街路、周辺の小街区 | 各公共室に駅・昇降拠点を隣接。徒歩だけでkmを上らせない |
| 約900〜1,600m | H地区から来る人の乗換広場、居住・学校・診療・商店の街区案 | 中央に来なくても生活が成立する地区サービスを保つ |
| 約1,600〜2,200m | 静かな公共庭、展望・学習・滞在の街区案 | 高所からW0とHERO4を眺める。全都市交通の乗換を頂上へ強制しない |

公共室間は複数の昇降系統と独立した退避先を設ける方針。600m程度を一つの広域歩行区間の仮上限とし、その間にも休息・小目的地を置く。巨大全体を一つの吹抜けや無柱室として主張しない。日常の道は10〜25m、地区広場は80〜150m程度、都市前庭は400〜900m程度という尺度差を比較する。いずれも概念値。

H1〜H6には個別に「地区内生活→既存交通→中央側受入れ広場→公共室→別系統の帰路」を確保する。全6地区を宮殿へ貼り付けない。高い地区からは中央の上部だけ、別の地区からは裂隙の内側が見える関係を検討する。地区の高度が不明なため、各H番号への特定階の割当ては行わない。

### 景観の連続

1. 都市外約10km：生活都市の連続した低い密度の上に、中央の片側へ量が移る巨大質量と空中地区が重なる。中央の単独塔ではなく、空白を共有する都市全体が見える構図を目標にする。
2. 都市軸で約3kmまで接近：SB09などの手前の施設、前庭の空白、中央の高い肩が順に現れる。どの施設が手前になるかは座標照合待ち。
3. 中央前庭：建築を正面から拝むだけでなく、側方から来る生活街路と公共室の活動が同時に見える。中央を貫く空白の奥にW0の空を残す。
4. 高高度地区：厚い屋根面の反復でなく、複数の公共室の屋根、採光裂隙、細かい生活街区と地上の空白を読む。
5. 内部：到着の圧縮空間→中規模前室→大きい集会室→外に開く公共の肩。遠方の都市を見ながら、同じ建物内の生活の明かりを近くに見る。

融合：Brasíliaの尺度と公共秩序＋Teotihuacanの接近の時間＋CCTVの活動隣接＋MBSの共有する高所。軸の終点を記念像から「活動で厚みが変わる街区断面」へ変えることが新しい構造である。

## 5. 案B《六庭共議都／交響公館》— 離れた中心の交換が一つの主役を生む

文明思想：文明を一つにするのは全員が同じ場所に集まることではなく、離れた場で生まれた知・決定・作品を、互いの生活へ還すことである。

### 都市構成・中央の外形

三大軸の既存の流れを保ち、HERO4・地区の目的地を結ぶ横方向の公共交通を充実させる。中央を通らない移動も成立させる。六つの地区それぞれに固有の公共庭があり、中央の「編集と交換の公共室」がそれらの活動を可視化する。六庭はH地区の正式名称の置換ではない。

中央主役は、**高さの異なる公共室の大きな塊が、ひとつの厚い縦の生活街区を斜めに挟み、接合面だけを深い公共の谷として開く多葉体**。四つの大きな室の塊と、相対的に小さい二つの地区受入れ室で非対称の密度をつくる。二本の塔を上部で閉じず、地上から立つ複数の太い根と室の膨らみを持つ。提案外接域は約3.2×2.5km、最高約1.9km。上層より中層に最大質量を置き、単純な頂点をつくらない。

公共室の上下に生活街区と設備があり、室の外壁は屋上庭と路地の背面になる。中央の谷は屋根で閉じない。W0へ連続できるかは原位置照合待ち。分散した施設をそのまま橋で全部つないで巨大ループにする構成は採らない。

### 活動と断面

| 活動関係仮説 | 中央側の形状への変換 |
|---|---|
| SB05の大規模な集い⇄SB06・07の討議 | 下部の大きな公共室と、それより小さい討議室が厚みを共有。式典の待機と日常利用を分ける |
| SB08の複数の内部体験⇄SB11の上演 | 中高度に二つの膨らみと屋外の音・光の庭。ひとつの均質な階へ整理しない |
| SB09の通過⇄SB10の乗換 | 谷の下端に無屋根の到着広場。交通は中央内部を貫通せず側方へ分流 |
| SB12の静けさ⇄SB04・14・15等の学び・制作 | 高所に静かな公共室を置き、外側に小街区。静けさの必要性が非対称の上端を生む |

地上〜300mに乗換・市・物流分離、中高度300〜1,100mに大公共室・討議・文化交流と生活街区、高高度1,100〜1,900mに地区受入れ庭・学習・滞在を置く比較仮説。施設本体の移設や用途変更ではなく、中央の新設空間側の配分である。全6地区が同じ階へ着く設計にはしない。接続は幹線→地区受入れ庭→室への短い徒歩で構成し、各庭は別方向に退避できることを条件とする。避難成立は未検証。

各施設を除くと、Aでは前庭の向きと肩の長さが変わるのに対し、Bでは部屋間の隣接関係と塊の個数・接合位置が変わる。SB08由来の活動を除けば中高度の二つの大室は一つの大きな空白へ変わり、主役の最大の膨らみも失う。この因果を図の形状操作で示すが、需要データに基づく容量計算ではない。

### 景観の連続と生活都市

遠景約10kmでは中央の中ほどが最も厚く、左右に異なる高さの肩を持つ。三大軸ごとに違う公共室の塊が現れ、一つの正面を持たない。接近景では施設同士の空白を通して別高度の庭が見え、中央広場では頭上の公共室の下へ人の集まる路地が入る。高高度からは六地区と中央の受入れ庭の関係を読む。内部では討議室から文化の庭、生活街路へ移ると用途の差が光・天井高さ・外形へ現れる。

生活街区は公共室の隙間を埋める飾りにしない。独立した玄関、商店、学校、診療、日常の交通を各公共庭に持たせ、巨大行事がある日も住民の帰路を遮らない。MBSの上空共有地を複数高度に分け、CCTVの活動連関を都市の複数拠点へ開き、Brasíliaの尺度秩序で住生活を分離しすぎず整理する。Teotihuacanの余白は一本の直線でなく、拠点間の景観の時間差へ翻訳する。

Bの根本リスクは、多葉体が巨大な岩塊の寄せ集めに見えることと、ネットワーク図としては合理的でも一棟の主役の輪郭が弱いこと。これを細かい窓で隠す修正はしない。
