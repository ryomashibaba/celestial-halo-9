# CELESTIAL HALO-9 — Independent Architecture Research A2

2026-10-22 / 独立構想研究 / ART-FIRST

**研究上の推奨：A案「双潮聖殻 — THE TIDAL APSES」を初回立体検証へ進める。正式採択・M247-C適合・Minecraft施工はHOLD。**

これは自由な建築提案であり、既存正式設計の改訂ではない。寸法は造形を具体化するための設計仮説で、構造計算・人口推計・施工計画ではない。付属図は主質量の関係を示す簡略包絡図であり、完成予想画像でも、内部都市まで検証した3Dモデルでもない。

## 1. 三つの異なる成立原理

### A｜双潮聖殻 — THE TIDAL APSES

**原理：都市を支える巨大骨組みを置くのではなく、居住する二つの厚い建築地殻を彫り、その間を都市規模の公共空間にする。**

1. **立体形**：西の高い殻と東の低い殻が、湾曲しながら互いの上方へ張り出す。二つは高さも奥行きも異なる。断面は向かい合う二つの鉤形で、左右対称の門・環・ドームには閉じない。西殻は大きく北側を欠き、東殻は南側を切り開く。
2. **都市の空間と質量**：厚さ600–1,200mの殻そのものが街区、大学、庭園、劇場、交通施設を収める。内側の数百m級施設の段差が、殻の内輪郭をつくる。二殻間は中央大湾となり、上部の重なりが第二の空をつくる。
3. **地上と高所**：共通の地上都市が両殻の足元へ入り込み、街路・斜行移動軸・連続する庭園を通じて上層街へ続く。上部も通常の下向き重力。最高部は尖塔でなく、厚い居住地殻に包まれた都市盆地。
4. **六方向**：南は開いた大湾、北は居住鞍部を伴う深い裂け目、東は低い殻越しの高い殻、西は高殻の厚い外背と切り込み、上は二つのずれた盆地、下は二殻の張り出し裏と裂光。正面以外で別の建築に見える程度の差をつける。
5. **内部の決定的景観**：中央大湾の水際から、対岸の大学都市を含む殻の内壁と、数km上で重なる都市地殻を同時に見る。頭上の地殻の縁にも樹林・広場・建築断面が読める。
6. **3Dの失敗リスク**：二本の曲がった塔、巨大な門、厚い配管のように見える危険。奥行き方向を均一に押し出すと、巨大な断面模型で終わる。外形と内部都市を同時に設計する必要がある。

### B｜七内天 — THE SEVEN INWARD SKIES

**原理：一つの地面を共有せず、七つの巨大な凹面都市が、それぞれ異なる重力方向を持って中央空洞を囲む。**

1. **立体形**：七つの多面体状の居住大陸が、中心からずれた位置に集まる。正多面体には整列せず、三つの大陸を上方、二つを側方、二つを低所に配する。各大陸の内側は椀状に深くくぼむ。
2. **都市の空間と質量**：直径1.2–2.4kmの凹面都市が、一つずつ独立した「内天」を持つ。外背は厚い記録庫・生命維持施設・資源層。中央には幅約3kmの、地面を持たない共通空域が残る。
3. **地上と高所**：地上都市は七つのうち最下層へ接続。重力が回転する移行街路を通って、側壁や頭上の都市へ移る。空中の大陸は文明固有の場によって位置を保つという設定とする。
4. **六方向**：南は二つの凹面が見える大開口、北は大陸間の狭い裂け目、東は側面都市の縁、西は閉じた大陸の外背、上は三つの上空大陸の谷、下は最下層都市の広い受け皿。どの方向にも正面を持たない群像建築。
5. **内部の決定的景観**：自分の街路の正面に別の都市の空があり、見上げると第三の都市の広場が逆さに続く。遠方の人々は別の重力で歩く。
6. **3Dの失敗リスク**：空中に浮く岩と、その上に置いた小都市の寄せ集めになりやすい。外観から都市の重力体系が伝わらず、内側だけが面白い案になる可能性。七つの質量を一つの建築として統合する難度が最も高い。

### C｜三河交織宮 — THE BRAIDED CONTINENTS

**原理：巨大建築に地盤を載せず、厚い三本の都市地盤が上昇・下降・交差し、その連続自体を建築にする。**

1. **立体形**：幅700–1,100m、厚さ250–550mの三つの都市帯が、低所から高度約4.8kmへ大きく折れ上がる。閉じた輪や規則的な螺旋にせず、上層で一度だけ三本の上下関係を入れ替える。
2. **都市の空間と質量**：各帯は複層の居住地盤。表面は街路・公園、内部は公共建築と移動、側面の大きな切欠きは都市の入り江になる。交差部は長さ1km級の駅・市場・集会都市。
3. **地上と高所**：三つの異なる地上地区から、それぞれ都市帯の連続をたどって高所へ達する。勾配部は斜面都市と局所的な重力調整を組み合わせる。上部には帯が幅広く肥厚した都市平原を置く。
4. **六方向**：南は三帯の上下交差、北は広い帯裏の連なり、東は上昇する都市断面、西は下降して地上へ戻る地形、上は三つの流路と大きな空隙、下は交差部の広い天井と都市の谷。
5. **内部の決定的景観**：一本の都市帯の市場から、その下を横切る別の街路大陸と、上空を覆う第三の大陸の公共施設を見る。三つの都市の時間が一つの景色に重なる。
6. **3Dの失敗リスク**：巨大高速道路、遊園地のコース、薄いリボンに住宅を貼った形へ落ちやすい。帯を厚くすると交差部が団子状になり、薄くすると高所の都市質量が消える。

## 2. 比較と選定

| 判断軸 | A 双潮聖殻 | B 七内天 | C 三河交織宮 |
|---|---|---|---|
| 主質量だけでの造形 | 二つの不均衡な厚い殻と、その間の空洞が主題になる | 七大陸の統合に強い構図設計が必要 | 連続と交差は強いが細長くなりやすい |
| 数百m級施設と外形の一致 | 施設の断面が殻の段差・開口・縁をつくる | 凹面内では成立、外背への反映が課題 | 帯の厚みと交差部で成立 |
| 地上から高所への都市の連続 | 二つの大きな斜行都市軸で明確 | 重力の切替が都市体験の核心 | 最も明瞭な地盤の連続 |
| 高所の厚い都市世界 | 頂部を居住盆地として固定できる | 上空大陸そのものが都市になる | 上層の肥厚を維持する必要 |
| 神聖80／異常20の調整 | 大空洞の静けさと頭上の質量で両立しやすい | 異常性が先行しやすい | 流動的で躍動感が強い |
| 最初の3Dで判断できること | 殻の太さ、重なり、開口、都市断面 | 群像のまとまり。重力体験は別途必要 | 厚み、交差、都市地盤の読みやすさ |

**Aを選ぶ。** 「壮大な空洞」と「上空の厚い都市」が、一つの断面で互いを強くするためである。Bは空間体験の発明として最も異質だが、外観統合の未解決点が大きい。Cは都市の連続性が最も強いが、細長い部材の美しさへ依存する危険が残る。

Aも完成保証ではない。初回立体で「二本の曲がった塔」にしか見えなければ、細部追加をせずに主質量を再設計する。現段階の判定は**立体検証へ進める価値がある**であり、正式合格ではない。

**包絡図を見た自己批評**：中央断面では空洞と上部の厚みを明確にできた一方、東西の側面はまだ大きな壁、俯瞰は閉じた屋根の塊として残っている。北の都市谷、南の切り開き、上層盆地の掘り込みは、この簡略包絡では表現できていない。したがって六方向の美術品質が達成されたとは判定しない。Aは発展候補として選ぶが、現段階で美術的な合格案は出さない。これらを主質量に組み込んだ低詳細モデルで改善できなければ、Aも棄却する。

## 3. 選定案：双潮聖殻の設計

### 3.1 一つの景色を決める

> 二つの都市大陸がゆっくり向かい合い、その間に残った空が、文明全体の聖堂になる。

建築の主役は中央の塔ではなく、「空を囲む、住まわれた厚み」。地上では殻が都市の丘陵となり、上空では地殻が天井となる。神聖さは中央の静かな空、長い水平線、石に似た厚い面から生み出す。異常性は、数km上で都市大陸が迫り、その間に空が細く残る一か所へ集める。

### 3.2 座標と全体寸法

東を+x、北を+y、上を+z。南側を代表正面とする。すべてkm。

| 項目 | 構想寸法・位置 |
|---|---|
| 周辺都市 | 直径約10。中心建築を囲むが、南北には広い見通しを残す |
| 主建築包絡 | 東西約6.8、南北約5.2、最高部5.6 |
| 西高殻 | 地上の中心x=-2.8付近から上昇。上部は東へ張り出してx=+1.0へ達する |
| 東低殻 | 地上の中心x=+2.7付近から上昇。上部は西へ張り出してx=-0.9へ達する。最高部4.3 |
| 西殻の厚み | 主要部0.7–1.2。頂部も約0.8–1.0の都市断面を保つ |
| 東殻の厚み | 主要部0.6–1.0。上端を薄い刃にしない |
| 中央大湾 | 地上付近の有効幅約4.5。高さ2付近では約3.6。中央の主要空間は地上から高度3.4付近まで続く |
| 重なる上端 | x=-0.9〜+1.0付近。上下差は場所によって0.35–1.0。完全に塞がない |
| 西の上層都市盆地 | 高度4.6–5.0付近、概ね東西2.0×南北2.8。実際の輪郭は欠き込みに合わせて絞る |
| 東の中高層都市盆地 | 高度3.3–3.8付近、概ね東西1.7×南北2.5 |
| 北の居住鞍部 | y=+1.5付近、高度2.0–2.5。東西約3.8×南北0.65の、施設を含む横断都市 |
| 南の上層継手 | y=-1.3付近、高度3.7–4.1。二殻の近接部を幅0.5–0.8の短い居住継手でつなぐ |
| 個々の大施設 | 長さ0.25–0.9、建築高さ0.12–0.35。殻内の空間群ではさらに大きな吹抜けを許す |
| 周辺地区の比較尺度 | 一般建築高さ30–120m、地区の節点200–350m。中央の施設もその地区に匹敵する |

これは位置関係を拘束する初期値である。盆地の寸法は矩形の平坦床を意味しない。境界は殻の湾曲に沿う段丘、街区、内庭へ分かれる。包絡の最大寸法と有効都市床の寸法を混同しない。

### 3.3 二殻を「曲がった塔」にしない形

**西高殻「記憶の岸」**：地上では幅広い根を持つ厚い丘陵。中腹で中央大湾へ大きく凹み、上方で再び肥厚して東へ張り出す。南端は太い鈍角の断面を見せ、北端は約1.2km奥へ切り込む長い都市の谷に割れる。外背には稜線を二本だけ通し、その間を浅い面へほどく。先端を細くしない。

**東低殻「生成の岸」**：西殻より低く、北へ約300mずらす。南側の縁を約1km後退させ、地上都市が内部へ入る口をつくる。上端は西殻の下へ潜り込む、丸みを帯びた厚い都市の岬。外背は西殻より穏やかで、深い一つの縦谷が大規模施設への入口になる。

二殻の南北方向の断面を一定にしない。少なくとも「南の開口」「中央の最深部」「北の鞍部」の三断面は別々に設計する。軸をねじる装飾ではなく、街区の深さ・公共空間・採光の必要が質量の変化として現れる形にする。

### 3.4 主要な空洞を三つに限る

1. **中央大湾**：都市全体が共有する最大の外部空間。南へ開き、北の居住鞍部が遠景を受け止める。中央に別の巨大塔を追加しない。地上には水面・広場・緩い都市丘陵があり、空洞の底にも都市活動がある。
2. **西の上層内海**：西高殻の頂部を彫り込んだ都市盆地。高度4.6km付近の庭園と街路、その周囲の大学・住居・大集会施設が、厚い縁の断面をつくる。北の大きな欠き込みが遠方の空へ開く。閉じた巨大室ではない。
3. **東の懸空庭**：東低殻の内側にある中高層盆地。西の上層都市が遠景の天井となる。南の切り開きによって、地上からもこの高所の都市床を認識できる。

二殻の重なりに残る細い**裂光**は、四つ目の巨大空洞ではなく、二つの都市の間を縫う採光の切れ目とする。途中に短い上層継手が横切る。天井を全面ガラスで塞がない。

### 3.5 施設が殻を構成する仕組み

| 建築群 | 概寸 | 主質量への役割 |
|---|---|---|
| 西岸の記録院・学術区 | 一群600–900m、断面高200–350m | 高殻の内側を深くえぐる三つの段丘をつくる。大空洞側に見える厚い庇は施設の屋根 |
| 東岸の庭園・居住区 | 一群300–650m、断面高150–250m | 低殻内側の広い階段状輪郭。屋根が次の街区の地盤へ続く |
| 北の市民会院・交通区 | 横断長約3.8km、南北650m、上下約450m | 二殻の接続であり、中央大湾の北端を受ける建築質量。内部に駅・広場・街区を持つ |
| 西上層の集会都市 | 複数の400–800m級施設 | 頂部の厚みそのもの。施設を除けば頂部の輪郭と都市盆地の縁が欠ける |
| 東上層の生態・居住都市 | 複数の300–600m級施設 | 東殻の厚い岬を構成し、下から見える天井と上の公共地盤を共有する |

各施設は大きな殻の上に載せる箱ではなく、殻の縁・大きな欠き込み・張り出し・段差に対応させる。境界は読めても、構造と都市が分離して見えないこと。住宅の細分や窓はこの関係を決めた後に扱う。

### 3.6 都市の移動と日常

南の地上都市から水辺の大広場へ入り、東西の街路がそれぞれ殻の足元の公共施設へ分岐する。そこから太い斜行交通軸が、数百mごとの街区広場を連続して結ぶ。歩行は地区内と段丘間で成立させ、全高度を一つの階段で歩かせない。

中高層では北の横断都市が両岸を結び、高層では二殻の近接部に短い上層継手を置く。地上・中高層・高層の三段階で街路系が接続する。中央大湾の中央断面には横断床を置かず、上下に貫く視界を守る。

上層都市にも住宅、学校、診療・ケア、食と日用品、市民広場、庭園、交通の結節点を持たせる。頂部を展望台や権力者の宮殿だけにしない。居住人口や自給率は、この段階では数字を付けない。

### 3.7 材質・光・異常性

主表面は骨白色から灰白色の、地層のような厚い鉱物質。遠景では大きな面として静かに読ませ、近景では施設ごとの継目が深い影になる。内側の段丘には淡い青緑の水面と濃い樹林、公共建築の奥に低い金色の光。発光ラインで全面を縁取らない。

神聖80%は、大空洞の静けさ、左右の不均衡を包む秩序、大きな光の面でつくる。異常20%は、上空で重なる厚い都市地殻と、空が切り取られる裂光に集中させる。危険を示す棘や武器の意匠を足す必要はない。

## 4. 六方向と内部・斜視の景観指定

| 視点 | 見せる建築関係 | 画面の主役／失敗判定 |
|---|---|---|
| 南・正面 | 高い西殻と低い東殻、開いた中央大湾、上端の重なり | 空洞の奥に北の横断都市。左右対称の門になれば再設計 |
| 北・背面 | 深い北の欠き込みと横断都市、その向こうに残る南の光 | 背面自体が都市の谷。継ぎ目を隠す平らな裏壁になれば失敗 |
| 東・右側面 | 低殻の厚い外背、南の後退部、その上へ現れる西の上層都市 | 二つの高さと奥行きの差。西殻が完全に隠れるなら位置を調整 |
| 西・左側面 | 高殻の二つの稜線、北の切込み、内部へ続く街区断面 | 大きな面と深い切欠き。無表情な厚い壁なら再設計 |
| 上・俯瞰 | 西上層内海と東懸空庭、ずれた二つの盆地、残る中央の空 | それぞれの盆地に都市地盤が読める。屋根一枚の塊なら失敗 |
| 下・見上げ／下面 | 張り出し裏、公共施設の大きな天井、二殻間の裂光 | 厚みと居住断面。単なる平滑な巨大底面なら失敗 |
| 南東・斜視 | 東の都市への入口、西の高い都市盆地、中央大湾を同時に見る | 全体を象徴する代表像。正面だけ成立する錯視を排除 |
| 内部・中央水際 | 手前の広場→対岸の数百m級施設→頭上の高所都市→裂光 | 四つの距離と尺度が同居する。この景観を最初の主検証とする |
| 内部・上層内海 | 手前の生活街区→盆地の厚い縁→下に見える東都市→遠方の地上都市 | 高所に本物の都市が存在する証拠。空中デッキ上の小屋群にしない |

「下」は地中からの実景ではなく、張り出しの裏側を見る検証方向。付属の下面図は包絡の投影であり、実景の見上げカメラとは区別する。

## 5. 初回低詳細3Dの検証計画

### 作る範囲

二殻の包絡、三つの主要空間、北の横断都市、南の短い継手、地上都市の地盤、そして外形を決める300–900m級の施設群まで。周辺都市は地区の大きさを示す少数の体積でよい。窓・住宅反復・小物・装飾・発光演出は不要。

薄い表皮だけで主質量を表現しない。殻の切断面には設計上の厚みを持たせ、その中に街区床と公共空間の抜きを最低限示す。高所の建築を一枚の床と少数の箱で代用しない。

### 必須画像

同じモデルから六方向の平行投影、南東・北西の斜視、中央水際・西上層内海の内部視点、y=0付近と北鞍部を通る二断面を得る。外観は同じ縮尺と無彩色の拡散光で比較する。内部は人の高さの視点に加え、街区関係が分かる中高度の視点も用いる。広角だけで巨大さを演出しない。

### 見るべきことと不合格条件

1. **輪郭**：窓も植栽も消した状態で、二殻の差、重なり、裂け目に美しさがあるか。二本の塔・左右対称の門・同じ断面の押出しに見えたら戻る。
2. **上空の質量**：高度3.5km以上を切り出して見ても、建築都市として成立するか。尖端・細い桁・床板だけなら不合格。質量の量だけでなく、その中の都市空間も見る。
3. **数百m級施設の必然性**：主要施設群を一群ずつ非表示にすると、内外の輪郭や都市床が実際に変わるか。外見がほぼ同じなら、施設は貼り物になっている。
4. **主要空洞**：中央大湾の奥行き、上層盆地の広がり、裂光のつながりが同じモデルで確認できるか。写真一枚だけで広く見える場合は不合格。
5. **立体的な都市接続**：地上→中高層→高所を、接続点と地区床をたどって説明できるか。移動線だけが面を貫き、到着先の街が存在しない状態を認めない。
6. **六方向**：弱い方向に施設や開口の必然性があるか。装飾を足してごまかさず、殻の奥行きと欠き込みを変える。
7. **尺度**：周辺120m級建築、中央600m級施設、5.6kmの主質量を同一画面で読めるか。小建築の数だけで巨大さをつくる案を避ける。
8. **陰影**：外側の大きな面は穏やかで、内側には深い影と到達する光があるか。霧や発光を消しても成立するか。

### 初回の感度比較

基準形に対して、(a) 上端の裂光を350m／600m／900mに変える、(b) 西殻の奥行きを約20%変える、(c) 北の横断都市を南北に約400m移す、の三項目を一つずつ比較する。候補全体を無秩序に変えず、空洞の荘厳さと上層の厚みが両立する範囲を探る。

**通過条件**：主質量の美しさ、高所都市の実在、施設と輪郭の一致、六方向の成立をすべて確認してから、詳細化へ進む。どれかが成立しなければ、不足を明記して主質量設計へ戻る。細部の追加で合格にしない。
