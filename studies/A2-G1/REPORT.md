## 3. A再検討：《双潮聖殻》— 住まわれる厚みで空を囲む

### 思想と主質量

西の高殻と東の低殻が向かい合い、上空でずれて重なる。都市大陸の厚みを彫ることで、大空洞と上層盆地をつくる。構想包絡は約6.8×5.2km、高さ5.6km。殻の厚み600〜1,200m、頂部にも800〜1,000m級の建築断面を保つ。

地上には中央大湾と水際の公共都市。高所には西の上層内海、東の懸空庭。大学・記録院・庭園住区の大きな断面が、内側の段丘と庇をつくる。中高層の横断都市と近接部の短い継手が二殻を結ぶ。

### 強み

一つの断面で「地上の都市・大空洞・頭上の都市質量」を説明できる。通常の下向き重力を保っても、頭上に都市大陸が迫る異常性を生める。静かな大空間と鉱物的な外面によって、神聖さを比較的制御しやすい。

### 弱みと再設計の条件

A2包絡図では、中央断面以外で都市が消え、東西が大壁、俯瞰が閉じた屋根となった。これは装飾不足ではなく、主質量の奥行きに都市空間が組み込まれていない問題。今回の思想を保つなら、南・中央・北の三断面を別の都市断面として設計し、北の谷と二つの上層盆地を外背へ貫く必要がある。

その修正後も「二本の曲がった塔に、後から空洞を開けたもの」に見えるなら、思想の実装に失敗している。門という輪郭自体を禁止する理由にはしない。

|---|---|

| 斜視 | 二つの上端の重なり、前後差、高所都市の床。奥行きによって初めて読める部分 |

## 4. B重点研究：《七内天・連体案》— 一建築に七つの地面

### 4.1 原案から変えること、残すこと

原案の「七つの独立した浮遊大陸」をそのまま美化すると、浮遊岩と住宅群になりやすい。そこで七つの都市の背側を、厚い公共建築の接合によって相互に連続させる。均一な球殻で包まない。外周に一つの壁を建てて七都市を隠す方法も採らない。

**七つは物体の数ではなく、内部の都市世界の数。** 各都市は固有の凹面地盤、重力域、空の方向、隣接都市との接続を持つ。七つの同じ椀を配置する必要はない。数自体に品質を保証する意味はなく、将来の審査で整理する余地は残す。

### 4.2 全体像と立体配置

構想包絡は幅約6.6km、奥行約5.8km、高さ約6.2km。三つの強い主質量が遠景の輪郭を決め、その間と内部に七つの都市世界が食い込む。正面の大開口は中心から東へずれ、上部の重い都市は西寄りへ偏る。背面は閉じた外壁ではなく、接合部の深い都市谷が縦横に残る。

### 4.3 重力は視覚効果ではなく都市の構成条件

各都市域では、生活地盤に沿って重力方向が変わるという架空の文明原理を用いる。都市の凹面と床の向きが対応し、家や樹木だけを表面へ垂直に貼る方法で代用しない。大施設の内部断面、街路、公共広場もその重力域に従う。

都市間の移行域は概ね200〜500m級の公共建築として扱う。入口側の街路が次の都市の壁面へ変わり、階層の向きがゆっくり変化する。重力場の工学・身体適応は未検証の設定であり、実現可能性を主張しない。

地上→I→II/III→IV/V→VI/VIIという複数の経路を持たせる。高さだけで社会階層を分けない。高所にも暮らしの機能が揃い、地上へ戻らず日常が続く都市とする。

### 4.4 巨大公共施設と外形の統合

- **転天市民院**：長さ600〜900mの重力移行施設。二都市の接合を形成し、外観では深い切欠きと大きな庇になる。
- **共空学府**：幅500〜800mの複合学術区。二つの内天を別方向へ望む大空間を持ち、その厚い屋根が隣接都市の地盤となる。
- **天頂の生活圏**：V〜VIIの周囲に400〜700m級の学校・居住・ケア・商業施設を組み込む。上端の都市の縁そのものを構成する。
- **内天の庭園港**：都市内交通の到着広場。船舶的な形状は必須でなく、局所的な重力の違いを受け止める厚い街区の継手とする。

施設を除くと外側の主輪郭、内側の空の縁、隣接都市の床のうち少なくとも一つが欠けるように設計する。「外殻→内側に小都市を配置」の順序から脱する判定である。

### 4.5 決定的な内部景観

地上の内海の市民広場から見る。手前では樹木が普通に立ち、対岸では別の都市の街路が上方へ折れ、頭上には第三の都市の公園が広がる。その背後には転天市民院の600m級の断面があり、もっと遠くに天頂の内湾の明るい縁が見える。

驚きの中心を逆さの住宅の数に置かない。別の都市へ続く大広場、長い庭園の地平線、公共建築の厚みで「別の地面が存在する」ことを伝える。中央の空は静かで、異常性は地平線の向きに集中する。

|---|---|
| 正面 | 偏心した大開口の奥に、向きの違う三つの都市地平線。丸穴を持つ岩にしか見えれば不足 |
| 斜視 | 開口の厚い縁、都市をつなぐ公共建築、上部の重い居住質量が重なる。七物体の輪郭が均等に並べば群島へ逆戻り |
| 側面 | 東は居住する厚い外背、西は重力移行施設に沿う深い裂け目。両側同じ断面の反復にしない |
| 背面 | 接合の谷が高所都市へ開き、市民院の側断面が都市を見せる。設備用の無表情な裏壁をつくらない |

| 内部 | 一つの生活圏から、別方向の地面で生活する二つ以上の都市が見える。逆さの小物だけでは成立しない |

### 4.7 強みと弱み

**強み**：主建築の高さを、距離だけでなく「地面の関係が変わる体験」に変換できる。高所都市が外観の頂部と内部の空を同時に構成する。A2の門とは異なる認識原理を持つ。

**弱み**：内側の発明が外観の美しさを自動的に保証しない。連体化を進めすぎれば穴だらけの岩、離しすぎれば浮遊島になる。重力の説明がないと一般の鑑賞者に伝わらない危険もある。七つのうち見える都市の数を増やすため、外形の静けさを失う可能性がある。

**現判断：主審査候補、未合格。** 外観の統合と重力の読みやすさを、別々の合否項目として審査してほしい。

## 5. C再検討：《三河交織宮》— 都市地盤の連続を建築にする

### 思想と質量

三本の都市地盤が低所から高所へ続き、一度だけ上下関係を入れ替える。幅700〜1,100m、厚さ250〜550mを基準とし、上層の主要都市域では厚さ700〜1,000m級へ肥厚させる発展余地を検討する。構想包絡約7.2×5.8km、高さ約5.2km。交通線を巨大化したものではなく、地盤内部に駅・市場・学校・居住区を持つ建築大陸とする。

### 強み・弱み

地上と高所の連続を最も明快に示せる。ある都市の屋根が他の都市の空を区切る景観にも力がある。しかし細い帯の交差は道路、厚い帯の交差は団子状の塊となりやすい。上層平原を広げると積層板へ戻る危険もある。数百m級施設が都市帯の縁と交差部を実際に変形させる必要がある。

### 六つの景観

| 視点 | 固有の関係／未解決点 |
|---|---|
| 正面 | 三帯の上下交代。線の綺麗さだけに依存しやすい |
| 斜視 | 帯の厚みと、その内部都市の奥行き。上面だけの街にしない |
| 側面 | 地上から高所へ移る都市地形。斜路の巨大化と区別する必要 |
| 背面 | 連なる帯裏が大きな公共建築の天井となる。単なる裏面になりやすい |
| 俯瞰 | 三都市の異なる街区と交差部の都市核。等幅の編み紐にしない |
| 内部 | 自分の市場の上と下に別の街路大陸がある。三者の尺度と距離の区別が核心 |

**現判断：今回は主審査候補から外す。** 発展可能性は残るが、主質量の美しさを都市の線的連続に依存する問題がまだ強い。曲面帯の禁止を意味しない。

## 6. 新構想D：《共晶聖都》— 公共建築どうしが巨大建築になる

### 6.1 従来三案と異なる成立原理

Aは厚い地殻を彫り、Bは異なる地面を統合し、Cは都市地盤を連続させる。Dは、まず互いに異なる大空間を持つ公共建築群を考え、その共有面と相互貫入から全体を成立させる。**主建築の空の器を先につくり、その中へ都市を詰めない。**

「共晶」は材料科学の実現性の主張ではなく、複数の異なる建築が同時に一つの塊へ育つ造形上の比喩。ファセット状の結晶外観は必須でない。

### 6.2 主質量と都市の構成

構想包絡は約5.8×5.4km、高さ約6.4km。少数の厚い根から立ち上がり、中高度でくびれ、高度3.8〜5.8kmで再び広い居住質量となる。頂部の一部だけが最高点へ達し、全体を細い尖塔に収束させない。

14〜18の主要公共建築群を、各々長さ600〜1,400m級の複合体として構想する。一つの複合体は複数の300〜900m級施設を含む。互いに上下だけでなく東西・南北・斜めに接合する。一つの議会大空間の厚い側壁が隣の都市の地盤となり、隣の図書都市の屋根が第三の公共広場へ続く。通常の下向き重力を基準とする。

全体を支える独立の外殻や中央の柱を後から足すことを前提にしない。km級の集合体としての輪郭は、公共施設の大空間、屋根、居住する厚い壁の相互関係から生まれる。

### 6.3 三つの都市空洞と高所の生活

- **下の市民湾**：地上から高度約1.6kmへ開く公共空間。市場・学校・水辺の地上都市が、公共建築群の足元へ連続する。
- **中の斜めの大峡**：幅約1.2〜1.8kmの、南東低所から北西高所へ抜ける空。巨大な一つの室ではなく、複数の公共建築の入口・側面・屋根が向かい合う都市の峡谷。
- **高天の共同庭**：高度約4.2〜5.4kmの、周囲約2km級の都市空間。高所の六つ程度の建築複合体が、住居・学校・ケア・商業・学術・交通を分担し、庭を囲む。高所の質量はこの庭の上下と側方へ連続する。

高所都市の地盤は一枚の広大なデッキにせず、各公共建築の厚い屋根・内部街路・広い閾を通じて連続させる。上下移動は複数の建築の厚い端部に分散する。地上から高所まで中央エレベーター一本で済ませない。

### 6.4 外形をつくる施設の例

| 施設複合体 | 主要な空間／全体への役割 |
|---|---|
| 天文公会院 | 約800m級の大空間。上部の張出しと、その下に残る大きな空の縁をつくる |

**強み**：数百m級施設とkm級主質量の統合を、最初から成立原理にできる。高所に複数の大空間を置くため、都市が薄い床板へ縮退しにくい。Bのような重力の説明なしに、公共空間の異常な重なりを体験できる。

**弱み**：施設の個性を強めすぎると巨大建物の寄せ集め、統合しすぎると内部不明の一塊になる。上下の共有だけを繰り返すと積層板へ戻る。全体の静かな輪郭と施設ごとの違いの配分が難しい。現段階では具体的な相互貫入断面をまだ描いていないため、施設名による文章上の統合にとどまる可能性がある。
