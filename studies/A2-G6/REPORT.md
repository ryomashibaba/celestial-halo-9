# A2-G6 — 交庭聖都：共有公共断面の実メッシュ研究

2026-10-23 JST / 担当A / art/a / **BLOCKOUT_3D / 美術HOLD**

**実3D制作と共有断面の検証は行えた。しかし、遠景で圧倒的な中央建築になる美術形式には到達していない。** 初期2案を停止し、主質量を作り直したC《多院連湾》を空間検証用に選んだ。Cも棚状反復の印象が強く、次の細密化候補として推薦しない。正式美術採択ではない。

## 継承と実行範囲

原本はG5 HEAD `b74e452f664adc8ae505846509d978e324fc6e1b` の `studies/A2-G5/REPORT.md`、`concepts.json`、`concept-I.png`。GitHubのファイル識別子とローカル原本を照合した。識別子は `inheritance.json`。G5案II《群街昇都》は変更せず独立対案として残す。

継承したのは、**下の街に開く公共建築の屋根が上の街の地盤になり、双方の生活が同じ公共境界を必要とする**という形成原理。G4の不合格メッシュは使っていない。G5模式図の梁・門型の形は固定せず、寸法・曲率・数・向きを変えた。

ライブBlender接続は利用できなかった。既存作業場内でBlender 5.2.1を独立したバックグラウンド処理として使い、実メッシュを生成・GLB出力・再読込・撮影した。別のWorkへの移行は行っていない。画像生成や外部モデルは使わない。

## 2. 一組の上下生活地区を作ったもの

下層街路の基準高度は2,110m、上層街路は2,206m。**96mの高度差**を持つ二つの近隣が、約700×480mの公共施設を共有する。下層の公共広間・両側の診療／図書の室群・途中階の回廊が、12m厚の屋根の下にある。屋根の上面が上層の街路と住宅・学校の地盤になる。

|要素|実際の形状|未実施・限界|
|---|---|---|
|下層生活地区|24の中庭型住宅街区。4翼、開いた中庭、入口の4mの切れ目、窓面、部分的な回廊。市場屋台、カウンター、庇、プランター、座席|住戸ごとの間取り、扉の開閉、生活設備・給排水はない|
|上層生活地区|8つの中庭街区と中庭型学校。学校の棟・窓面と校庭を形状化|教室・住宅の全室・家具までは設計していない|
|共有公共建築|屋根／上層地盤は同一のメッシュ。下の公共広間、両側の厚い室群、柱、途中階回廊|柱・室群は実幾何だが、荷重経路と耐力は未検証。巨大公共広間の運営は未設計|
|共有街路・広場|下層街路、市場前の広場、上層の横断街路、学校前、階段への接続床|全路線の歩行面・頭上空間・衝突を網羅検査していない|
|階段|16フライト、各40段、蹴上0.15m、踏面0.30m、幅4.5m、折返し踊場を実メッシュ化。合計上昇96m|段差・踊場の設計値と実形状の存在を確認した段階。避難規定、疲労、バリアフリーの合格ではない|
|都市交通|地上到着床、2本の昇降シャフト、キャビン、下層・上層の乗降床|作動するエレベーターではない。運行能力・待ち時間・他高度への全路線は未設計|

住宅街区を単色の箱・文字・色マーカーだけで置き換えていない。ただし遠方街区は住戸の室内まで持つ完成住宅ではなく、開いた中庭・入口・窓を持つ低詳細の建築形状である。「棟の形がある」ことと「居住可能性を証明した」ことを区別する。

通常の下向き重力と水平な住戸床を用いる。高所気圧、温熱、風、給排水、保守、複数の退避先は未設計であり、工学上居住可能な都市とは判定しない。

## 3. 人間視点で発見した干渉と修正

初回の眼高1.65mの人間視点では、主質量側の室群・柱が公共広場への見通しを大きく塞いだ。視線中央の最初の主質量干渉は約98.92m先の `INHABITED_BACK_ROOMS_AND_CIVIC_PIERS`。`comparison/C_initial_human_blocked.png`を失敗記録として残した。

カメラを移して隠すのではなく、共有広場・進入街路に重なっていた主質量側の室群を生成対象から除き、同じ修正モデルから全景・正面・側面・背面・俯瞰・人間視点を再撮影した。さらに主地盤と重点地区の地盤が同じ平面に重なる部分を除き、床面の描画不良を修正した。診断用の柔らかい補助光も加えたが、建築照明計画ではない。途中の暗い画像も`comparison/C_after_room_removal_dark_floor.png`として保存する。これは対象範囲の干渉修正であり、建築全体の衝突解消を意味しない。室群を除いた部分の構造支持は未解決のまま残る。

人間視点は市場・公共広間・上層街路の関係を確認するための画像である。人型は1.7mの尺度用形状で、実住民・生活実績・人口推計ではない。**修正後も公共広間が大きすぎ、日常の街路や市場の密度が小さく、生活する巨大文明都市より大架構の空間に読める。人間視点の最重要条件も未達と判定する。** 形状があることから都市生活の成立を宣言しない。診断用補助光のある人間視点は露出−2で出力し、初回失敗画像との照明・露出は同条件比較ではない。

## 4. 5km高所と全体質量

最終GLBの建築包絡は、幅約3,794.88m、奥行約4,199.88m、高さ5,514m。背景・照明・カメラを含めず、地上到着床・昇降設備・尺度人型を含む建築データ全体の包絡である。Blender再読込と別ライブラリtrimeshで同じ座標系に変換して測定した。

高所には5,100m・5,450m級の実際の都市地盤、中庭街区・公共中庭棟があり、尖塔だけで高さを稼いでいない。一方、その断面は反復する水平地盤と室群に依存する。高所まで広がる都市の量は表現できても、G5で目指した静かで圧倒的な主役の輪郭にはならなかった。

`dimensions_m`はこの実モデルの測定値。約10kmは概念背景地盤の幅であり、中央建築の寸法ではない。G5の4.8×4.2×5.8kmは当時の提案値で、今回の測定値へ書き換えていない。

## 6. 検証と美術を分けた結果

- GLBを書き出し・再読込し、別のtrimeshでも読めた。座標の有限性と包絡を確認した。
- 下層24＋上層8街区について、中庭中心だけでなく外周角・住宅翼位置を7点ずつ、計224点で対象の地盤への接触を確認した。全建築の全面支持・耐力・施工可否の判定ではない。
- 上層街区が接する地盤は、下層公共広間を覆う同じ屋根メッシュだった。屋根を取り去れば上層の当該地盤も失われる。ただし構造上の安全性は証明していない。
- 窓は実際の薄い面、壁や床は実厚のある形状。窓面は意図的に開いたメッシュで、モデル全体を閉じた単一ソリッドと宣言しない。室群同士の交差・重なりも残る。
- 正面・側面・背面の生活地盤は存在するが、都市の複雑な生活より棚状架構が支配する。**数値検証を根拠に美術合格や都市完成を宣言しない。**

## 次工程の判断

共有岸の実体を、上下の街区・公共広間・同一屋根地盤・階段とともに作れた点は、G5模式図からの進歩である。しかし、**居住する都市そのものが遠景の圧倒的な美術形になるというG6の最重要目標は未達**。

Cを窓・植栽・住宅数の追加で仕上げる工程には進めない。継承するのは一組の共有断面と干渉の教訓。次の構想で変えるべきは、全高にわたる似た水平地盤の反復と、細い支持域に街を載せる読み方そのもの。G6はこの失敗も含め研究履歴として提出し、中央監督の判断を待つ。
