# CELESTIAL HALO-9 — M3D-1S/J7-R3 研究報告

**2026-10-24 JST / 独立アート試作 / NONCANONICAL / 正式採択0件 / Minecraft施工HOLD**

## 目的と結果
J7-R1は段床と小建物の寄せ集め、J7-R2は巨大な滑らかな岩塊となって美術REJECT。J7-R3は、色で塗り分けた穴や不透明なSDF岩塊ではなく、**街路床・巨大公共室の実形状・露出した居住断面・非対称な上昇線・切り裂かれた空中都市地盤**を別々の編集可能な3Dメッシュとして制作した。2段階の実レンダー確認により、R3-Aの薄い板／帆に見える欠点を発見し、R3-Bでは厚い都市断層を個別に造形し、実際の公共階・公共室を増設した。

**技術上の改善があっても、美術はREJECT。** 側面・背面・遠景では「巨大な折り紙／宇宙船のような帆と装飾棚」に見え、生活都市と巨大公共室の一体性が弱い。外見の独創性が上がっただけで都市として成立したとは言えない。

## 本当に実施したこと

- 1個の研究用GLBを生成・再ロード、8視点からVTKで描画。同一都市比較の7視点はJ7-R2と同じカメラ位置・同じ尺度。8番目は局所ビューとして比較除外。
- 大きな居住断層体5個（不規則な凹形の実ボリューム）、幅広い都市地盤4帯、主要な折れた都市屋根3体、実床を持つ複数の公共室、縦交通ガイド、3系統の交通路を別ノードとして作成。
- R3-AからR3-Bへの修正では形状を実際に編集し、8視点を再レンダーした。画像生成AIの独立した絵ではない。
- 認可された3D構造体・実歩行・完成した一般建築外観を作れたという意味ではない。**Blender GUI／Blender-MCP接続なし**。今回はPython/Trimeshで幾何を製作し、VTKで観察した。

## 実技QAと美術審査の分離

**技術PASS範囲**：GLB保存・Trimeshでの再読込・メッシュ・正確なカメラ数・8 PNG描画・研究材質ロールの保存。

**検査していない範囲**：建築内部の使いやすさ、歩行の連続性、勾配、全体の支持構造、玄関アクセス、公共室への全出入口、地下街、Blenderレンダー、W0/16巨大施設/6空中地区の完全設計。

**美術REJECTの理由**：モデルが「高度で洗練された文明都市」より「大きな帆と重ねた通路」に見える。真横視点で巨大な居住質量を見せられず、背後からは建築の公共空間が見えない。実際の巨大屋内空間と都市断面が共通の思想で結ばれていない。数値やGLB保存を美術PASSに変換しない。

## 次ゲート（J7-R4への提案、未実施）

R1-R3で**(1)棚積み、(2)SDF岩塊、(3)折り畳み帆**のどれも中央主役に足りないことを確認した。次は同じ製造法による長尺モデルを連発しない。

- Blenderローカル実編集が本当に使える環境で、モデルの正面・側面・背面を見ながら**一つの巨大公共室を抱く本物の複合建築断面**を直接編集する。市民の街路・駅・巨大内部室・厚い住居都市の接続関係から出発する。
- 変更後の同一GLBを7方向／内部から再取得し、建築の外観が「船／岩塊／棚」に戻ったら即座に切替。
- わかりやすく巨大な主質量と、実際の人間が生活する高度の街路／公共空間を優先。周辺都市全域の3D完成義務を軽減せず、正式施工HOLDを維持。
