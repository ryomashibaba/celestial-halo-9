# CELESTIAL HALO-9 — M3D-1S/J7-R1 造形研究・厳格な失敗判定

**2026-10-24 JST** / ART-FIRST / CITY MASTER 3D FIRST  
**研究段階：実3D試作と多視点観察まで実施。中央美術：REJECT。正式採択：0件。Minecraft施工：HOLD。**

## 確認した固定方針
- 10km級都市全体を、一般建物の私的内部のみ簡略化可能な、詳細かつ編集可能な3Dマスターとして完成させてからMinecraft施工を検討する。W0・H1〜H6・SB01〜SB16・HERO4・全一般建物外観・公開内部・交通も必要。
- 中央主役は約10km都市にふさわしい巨大な建築質量、実在する巨大公共空洞、高高度の住める街区、非対称性と多方向の美術成立を求める。
- M247-C《浮断天核》は研究方向として保護するが、具体形状の正式採択は0件。他系統の独立美術試験は可能。未許可のmain、Freeze、正式Minecraftワールド変更・マージは禁止。

## J7-R1で本当に行ったこと
J7-R0時点では未実施だった、実GLBの制作と多視点実レンダリングを**クラウド外のこの会話の計算実行環境**で行った。Blenderの実接続ではなく、生成はPython/Trimesh、表示はVTK 9.6 offscreen。モデルの画像生成AI絵ではなく、**同一の実GLBのカメラ投影**である。

1. 試作前半は円形に積み重なる左右の巨大タワーとなり、都市質量として不合格。
2. 後半は円形積層を廃し、非円形の幅広い都市断崖・各高度の街区・空中公共通路・多段交通・巨大公開室の実開口形状・3層の架橋へ変更。
3. 変更後のGLBを独立に読み直し、7方向の同一10km比較縮尺＋局所詳細1視点の合計8枚のPNG実レンダリングを生成。
4. 結果は**REJECT**。側面と遠景から見ると無数の段床と小建物の集合／ラック状構造に見え、都市級の連続した主役建築にならなかった。旧M247の弱点と類似するため、この形を延命する細密化は行わない。

## 美術としての判断
**中央美術: REJECT, formal accepted count = 0.**  
プロシージャルな板・箱・都市段床・円形足場を繰り返し配置する方法を続けても、中心となる「一体の巨大未来文明建築」の造形が出現する保証がない。2回の視覚フィードバックにより同種問題を再確認。技術的なGLB/レンダーPASSと美術FAILを厳格に分離する。

## 次工程 J7-R2: 制作方式を切り替える
Blender等の実ソフトで、**数km級の統合した主形状と内部公共室を直接視覚編集する**方式へ切替。正面・側面・斜視・俯瞰を繰り返し見ながら、外形・公共空洞・住める断面を同時に編集する。箱・板・殻の自動一括生成から始めない。建築美術が改善しない場合は直ちにSTOP。Minecraft変換可能性はこの初期造形を制限しない。

このJ7-R1研究は**正規M247-C原本の変更ではない**。正式Minecraft施工、公式ワールド、Freeze、main、既存のJ3〜J7-R0研究原本に変更を加えない。
