## 2. R24で新しく設計したもの — 「3地区・3公共空・13目的地」の空間プログラム
こちらは**暫定的な研究座標とシーン構成**であって、正式HALO-9の確定座標ではない。実際の造形・道路・歩行可能性・視認性の確認はゼロ。自由な建築形状に合わせた大胆な改訂を認める。固定するのは**ユーザーの美術ゴール**と「都市世界・接続を同時に成立させる設計順序」である。

- **D1／海辺・低位都市**：都市の入口、生活市場、地峡の公共広場。外側の水面と中の街路が連続し、床だけでない近景の街路断面を持つ。
- **D2／中層・居住断崖都市**：実開口のある断面街区、居住と公共の多段経路、交通結節点、公開下面街路。単なる地盤の厚さではなく、用途と内部へのアクセスが外形を規定する。
- **D3／天空・背面都市**：複数の大公共室、空中生活街路、背面の第二都市正面、遠景に存在する公共到達広場。単なる頂上の展望棚ではない。

**正面だけの4.6km一本道を模倣しない。** 低位から高位へ進む主経路に加え、西側・東下面の分岐と合流があり、視線が前・横・背・上へ切り替わる構造とする。具体的な13ノード/17辺、3ボイド、6カメラ仮説は [R24_SPATIAL_PROGRAM.json](R24_SPATIAL_PROGRAM.json) を正とする。

- 主経路：潮門 → 水辺市場 → 地峡広場 → 交差広場 → 交通ハブ → 中空市場 → 上空広場 → 背面大通り → 天空到達広場
- 西側ループ：交差広場 → 西居住断崖 → 西遠景広場 → 背面大通り
- 東下面ループ：交差広場 → 下面居住回廊 → 東連絡広場 → 上空広場
- 仮想グラフの全13点は連結、閉路ランク5。この**グラフ上の通行関係は、実メッシュの歩行経路・エレベーター・道路・閉鎖空洞の検証ではない**。
- 主ルート直線区間合計の設計上の下限値は約 8.99 km。完成道路長とは呼ばず、寸法の良し悪しのスコアにも使わない。

**3つの連続公共空**：地上〜中層への公開空（V1）、中層の東西都市を分ける空（V2）、上空〜背面を貫く公共空（V3）。いずれも最終シルエットとの一体化を要求する。詳細数値は別JSONに格納、狙いは数値ではなく実際の場面の多様さ。

## 3. 次の実3D用：逆順を固定する制作プロトコル
0. **原本保護**：R23を「ベースモデル」にしない。R21/C55-Aは参考・比較証拠としてのみ読む。ユーザーが後で別美術形式を選んでもよい。前面操作・ローカルWorkは毎回明示承認制。
1. **先に生活する場所を小さく実形状化**：D1の市場街路／D2の断崖内外の公開路／D3の上空公開広場について、床、公共開口、建築の主要境界、行先の入り口を実メッシュ化する。これは全地区の詳細化ではなく、**同じ仮想世界座標に立つ代表的3点**の「建築の種」。
2. **種と種を空間と交通で接続**：V1-V3・二本の分岐経路・実交通結節を1つの実3Dに重ね、切削穴だけでなく公開空の立体的な囲まれ方を先に確定する。上下移動の実機能は初期ラフでは認証しないが、通る場所と接続先は必須。
3. **都市断面から全景を同時に統合**：建築外皮は地区の公開路・部屋・地盤から成長させる。面の表裏どちらも住める建築景観として成立させる。巨大殻／床／塔を禁止しないが、何も通らない・住まない面積を巨大化させない。
4. **極小美術ゲート**：低解像度・クレイの外観6方向＋床上4方向（入口、中層、上層、裏／下面）だけで早期判定。C55-Aの長軸優位を下回るなら装飾も重いQAも即停止。
5. **弱い場合の処理**：抽象的な形の2回目・3回目の小改変を自動生成しない。「視点で確認できた欠陥」→「都市プログラム／交通／公開空のどれが破綻か」→「構成手法の変更」を先に記録。美術が悪い形の写真を増やすことは禁止。
6. **有望な場合のみ**：内部街区の分節、実断面2方向、GLB/BLEND保存QA、公共経路の段階的認証、構造・統合可能性の評価。正式採択とMinecraft施工は別承認。

## 6. 再発防止の運用ルール（R24研究提案、全プロジェクト一律ではない）
- 未検証の項目を「合格」「改善」と報告しない。仮の座標やグラフの接続を現物と取り違えない。
- **同じ結果を生む手法の修正を自動で2回繰り返すことを禁止**。1回の失敗で方法変更の分析が必要。建築家として構造と都市の関係を再考する。
- 最初に比較すべき画像・視点を前もって決める。ユーザーの「一区画感」「規模感」「美術的価値」を最重要指標とする。
- 形状の自由、神聖80/危険20、M247-C他の保護、正式採択と施工への承認境界は今後も絶対に破らない。
