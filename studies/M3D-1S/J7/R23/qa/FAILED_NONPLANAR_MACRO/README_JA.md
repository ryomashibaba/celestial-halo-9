# 主質量欠落の失敗証拠

第二主形状修正の最初の実行では、大きく非平面となる側面四角形のままExact Booleanへ渡した。その結果、主母体は21頂点11面に縮退し、上層地盤だけが残る画像となった。美術上の改善として扱わない。

`R23_FAILED.blend` と `oblique.png` はその実物。修正後はBoolean前に側面を三角分割し、各切削の前後に部材数を記録。主母体は184頂点152面となった。最終成果・最終レンダーはこの欠落版と区別する。

初回地上視点の黒い重複面は、公共軸床と同一高度に置いた確認パッドの重複が原因。修正版でパッドを除去。最初の中高度位置は地盤内との関係が不明確だったため、最終版では実切削した中央中庭床へ移し、別位置として表示する。カメラ変更を美術改善だけによる比較として扱わない。
