# D28 — 実GLBの6視点観察・局所編集ワークベンチ

このツールは CELESTIAL HALO-9 の**隔離した技術研究用**です。都市本体、M247-C原本、Minecraftワールドへの施工はしません。建築美術採択も行いません。

## 必要環境・起動

Windows 11 と Python 3.13を想定。Pythonのモジュールをまだ入れていない場合、一度だけ次を実行します。

```powershell
py -m pip install -r D28_requirements.txt
```

その後は `D28_WINDOWS_ONECLICK.bat` をダブルクリックします。ブラウザで `http://127.0.0.1:8768/` が開く想定です。実環境のWindowsでの起動検証は未実施です。Windows以外では `python d28_visual_workbench.py --output D28_WORK --port 8768` で起動し、上記ローカルURLを開きます。

起動直後は**中立の二つの球形技術モデル**です。自分のGLBを開く場合は画面右側の「手元の.glbファイルを読み込む」を使用してください。読み込んだファイル自体には書き込みません。対応範囲：少なくとも1つの独立メッシュで、GLBシーンの配置変換がidentity、インスタンス参照なし、16MB以下。一般的なGLBを全てサポートするものではありません。

## 編集手順

1. 南・北・東・西・俯瞰・斜視のいずれかの画像をクリックし、実表面のメッシュと頂点IDを選びます。
2. 影響半径とX/Y/Zの移動量を入力し「実GLBを編集」を押します。
3. 編集前・編集後・赤い画素差分を切替えて6方向の変化を確認します。
4. 必要に応じて「1手戻す」。GLBと編集履歴JSONをダウンロードできます。

過大な変位、ゼロ半径、原本SHAの不一致、履歴のリビジョン衝突などは拒否します。D27由来の研究用GLBでは`civic_spine`と`civic_plaza`を編集拒否しますが、全ての重要な都市資産に対する汎用保護装置ではありません。

## 検査

```powershell
py d28_test.py
```

テストでは保存GLBからの6方向描画、クリックの3Dピッキング、編集、Undo、SHAによる再現、無効入力拒否を行います。`d28_browser_check.py` はPlaywright/Chromiumが追加で必要です（通常起動には不要）。今回の実行環境ではブラウザーローカル通信が制限され、ブラウザーのHTTPトランスポートだけをTestClientに置換して検証しました。
