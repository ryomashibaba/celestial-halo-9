# CELESTIAL HALO-9 — R18-E5 観察→実BLEND局所編集→同視点再審査 契約

**2026-10-31 JST／非公式G0技術研究／ART未採択／CITY MASTER 3D FIRST厳守**

## 根本理由

E0～E4の真正BLENDと実画像が示したのは、形状を一度に大量生成してから絵を見ても、巨大な無地面・抽象の箱と帯・スタジアムへ陥り続けること。前回の不合格E4原本は保護し、追加編集しない。

E5は**別に新規制作した一室のみ**で方法変更を試す。その作品自体が正式の未来都市作品に合格すると事前に約束しない。

## 逐次実行を必須とする

1. **Stage A — 現物：** 新規室内をBlenderで1回制作、編集可能なBLEND保存、入口・側方の人間視点＋斜視2つの固定カメラで本物の画像を作る。
2. **Stage Aレビュー — 画像を実際に見る：** 正面を遮る位置・外壁の画面比率、奥の公共展示や実際の学習場が見えるかを独立観察。どこをどう変えるかをそのレビューから具体的に決める。コードを書いた段階では達成扱いしない。
3. **Stage B — 原本を本当に開く：** Stage Aで保存したBLENDを直接 `bpy.ops.wm.open_mainfile` で再読込し、Blender内の**既存の同じオブジェクトのメッシュ頂点・面**を編集する。Stage A生成スクリプトを再実行しない。
4. **厳密な差分：** 頂点ID、モデルオブジェクト名、座標変更前後、削除・追加面数、全オブジェクト名の差、カメラ行列、無関係オブジェクトの形状ハッシュ不変を可能な限り記録。カメラ移動や色変更だけの偽改善を禁止。
5. **同一シーン・同一カメラ比較：** BEFORE/AFTERを真正画像で並べ、人間視点の遮蔽が物理的な主形状の編集で改善したか観察。遠景・背面で破綻したなら不合格。自動ピクセルテストは補助に限り、ART PASSは実画像から独立判断する。
6. **独立再読込・負の監査：** 編集後BLEND/GLBを別処理で再読込してソースの再現性検査。安全な通行・構造荷重・避難等を未検査のままFUNCTION PASSと言わない。

## 特に重要な失敗条件

- G0の固定カメラが黒・灰色の塊で占有され、展示を隠すなら、**対応する既存の主要メッシュだけの変形**で改善する。
- 原本を捨てて新しいコードを一括生成するだけなら、「新方式」失敗。
- 同じモデルのカメラだけ動かして「前後比較で改善」と主張したら失敗。
- ベンチ・窓・LED等の飾り追加のみで、主形状を変えなければ失敗。
- 画面内での展示の見え方が良くなっても、作品の美術品質が低ければ **TECH METHOD限定PASS／ART REJECT**。
- 旧E4のREJECTを取消・新モデルE5を正式中央へ採択するには別の厳格な判断が必要。
