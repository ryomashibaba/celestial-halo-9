**2026-10-30 JST／技術研究ツール／正式中央美術採択0件／Minecraft施工HOLD**

## 最初に：何を作ったか／何を作っていないか

R11は新しい中央建築ではなく、**画面で実3Dを見て直接編集し、固定した複数視点の証拠を一度に保存するための編集環境**を実際に作る段階。

過去のJ7-R7ではX11上の本物のBlender GUIで既存建築のメッシュをキーボード編集し、別プロセスで形状変化が成功した。本R11はその再実装ではなく、UIと原本保存と固定カメラによる**使い回せる制作道具**の実装検証。

- `R11_OPEN_IN_BLENDER_VISUAL_SCULPT_STUDIO.blend`はBlenderで開けるネイティブ編集ファイル。
- 明確に試験用と分かる細分化した**中立メッシュ1つ**。独自の未来都市の完成像やM247-Cの提案ではない。
- 固定カメラ6つ：正面、側面、斜視、反対側、低所・公共視点、高所・別世界視点。
- `R11_RUN_THIS_FOR_NATIVE_ART_TOOLBAR.py`はBLEND内部に同梱されたテキストブロック。Blenderを開いてから明示的に実行することでサイドバーの`HALO9 Art`を登録する。
- R10で厳密に再照合した4系統のGLB比較画像をBLEND内へPACK（読み取り専用の**参考画像**）。これらは全部不採択、または詳細化STOPを伴うHOLDであり、コピー・正式美術採択する意味ではない。
- 美術制作は実際のユーザーがGUI上で行う。GitHub Actionsの仮想ディスプレイ試験は**自動化された実GUI入力**であり、アーティストの創作・Work・ユーザーPC操作ではない。

## Windows・Blender 5.2.1での最小操作

1. R11の`.blend`を取得し、WindowsのBlenderで開く。
2. Blenderの **Scripting** タブを開き、Text Editorのリストから`R11_RUN_THIS_FOR_NATIVE_ART_TOOLBAR.py`を選んで **Run Script**（Alt+P）。スクリプトは同梱済みで新規にコピーペーストする必要はない。
3. **Layout** に戻り、3Dビューの右側サイドバーを`N`キーで開く。**HALO9 Art**タブから固定カメラを切り替えられる。
4. `R11_EDIT_ONLY_UNAPPROVED_STUDY_SURFACE`はただの中立テスト面。頂点編集／スカルプなどで全体の形の編集方法を試す。**そのまま都市として使わない**。
5. **Freeze revision: BLEND + GLB + 6 views**を押すと、編集後原本を上書きせずにファイル横の`R11_ARTIST_REVISIONS/R11_REV_001`等に別のBLEND、GLB、6視点PNG、ハッシュ付きJSONを保存する。

**注意：** Photoshop的なワークフローと同一ではない。これは本物のBlender編集ビュー、固定カメラ、ネイティブ保存、GLB輸出をまとめた小さな作業補助であり、自動的に都市美術を創るものではない。実案件の立体を差し替えてスカルプする前に、誤編集禁止の正式原本とResearch用編集コピーを必ず分離する。

## 独立QAによる本物の編集確認

GitHub Actions上では、実GUIのBlenderウィンドウをXvfbで起動し、試験用メッシュの**可逆シェイプキー**を編集モードでX方向に30m移動し、GUIからCtrl+S保存。実スクリーンショット前後を保存する。

別のBlenderプロセスで基準のBLENDを再読込して、編集対象メッシュのシェイプキーの頂点変化と元`Basis`の不変性、6カメラの座標、編集基準原本SHA256の不変性を照合する。

**カメラ切替とFreezeボタンは、Blenderの演算子を登録して呼び出す独立単体試験**であって、GUI上のボタンを実際にマウスでクリックしたとするものではない。6枚の画像は一つのネイティブチェックポイント形状から本当に描画し、GLB/BLENDを別工程で再読込する。

こうした条件を満たせば`TECH限定PASS`とする。ただし**美術のPASSではない**。中立試験形状を実際のユーザー制作物と混同しない。
