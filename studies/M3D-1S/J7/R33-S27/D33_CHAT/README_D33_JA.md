# CELESTIAL HALO-9 / D33 — Visual Sculpt Research

## 位置づけ
正式中央建築ではありません。**ART REJECT / TECH LIMITED PASS**。既存のD23〜D32不採用形状、main、保護M247-C、Minecraftワールドは編集しません。ZIP内の研究用中立3Dだけが対象です。

## 成果
- 3件の独立した7×7×3制御点ケージから、3枚の自由曲面の厚み付き・水密メッシュを生成。各メッシュ5,408頂点／10,812三角形。GLB全体32,436三角形。
- 編集中の制御点は **3×49=147点**。形状はBASE、5点の制御点を変更したEDITの2種類を作成。
- モデルは実GLB。VTKレンダーは正面・左右・後方・俯瞰・地上1.7m位置の6視点。これは**造形の観察のみ**であり、居住空間内の人間視点ではありません。
- BASEとEDITを別一時ディレクトリの独立Pythonプロセスから再生成し、両GLBのSHA256がそれぞれ一致。
- Web画面では制御点名・座標の編集→最新実GLBの保存→Undo→GLB/制御点JSON取得が可能。WebGL対応環境なら3Dプレビュー回転・制御点クリックを想定。**今回の隔離ChromiumではWebGLが利用できず、3D回転/点クリックを検証していません。** 代わりに実GLBをVTKで描いた6方向画像へ自動フォールバックする動作を実ブラウザー確認しました。
- HTTP通信はローカルAPI単体でPASS。ただし隔離Chromiumではlocalhostが管理制限され、ブラウザーテストは通信をFastAPIテストクライアントに接続するshimで確認。**Windowsユーザー実機での本番動作は未検証**。

## Windowsで使用する場合（実機未検証）
1. ZIPを展開する。
2. `D33_WINDOWS_ONECLICK.bat` をダブルクリックする。Pythonと事前インストールされた依存ライブラリが必要。初回に不足した場合は同フォルダーで `python -m pip install -r D33_requirements.txt` を実行。
3. 起動後にWebブラウザーで `http://127.0.0.1:8843` にアクセス。
4. 編集対象と制御点（7×7）を選択し、XYZを指定して「選択点を編集」。GLBと制御点JSONはWeb画面から取得可能。変更ごとの出力は `runtime_exports/` に保存される。
5. WebGLが無効な環境では、操作後に再描画される6方向のVTK画像を見る。マウスで頂点を引きずる形式の編集には未対応。

## 注意事項
- 表示はGLBの軽量なメッシュ。エクスポートはフル解像度（3×10,812三角形）。
- 各メッシュは個別に水密だが、自己交差と多メッシュ間の干渉は未認証。**橋・人が使える公共室・居住棟・歩行連続性は未制作。**
- 形がD32と異なることだけを美術成功の根拠にしない。今回は大きな彫刻であり**ART REJECT**。
- 制御点の編集は有限範囲に制限し、元GLBは上書きせず履歴別名で保存。変更入力が安全な建築を保証するものではない。
- VTK画像の地面は**レンダリング専用スケール参照**。GLBには含まれない。

## 再現実行
```powershell
python d33_sculpt.py
python d33_render.py
python d33_test.py
python d33_browser_test.py
python d33_independent_audit.py
```
`d33_browser_test.py` は研究環境でのブラウザー通信制限を回避するため、実APIに接続するテスト用の通信shimを使用します。ブラウザーの実ネットワーク通信を保証しません。
