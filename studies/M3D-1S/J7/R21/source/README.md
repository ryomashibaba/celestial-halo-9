## 1. 構想（空間思想）
**「山を割る光の廊」。** 全長約4.6kmの巨大な**裂け目廊（Rift Nave）**が、段丘状に居住する巨大山塊を縦に割る。裂け目を、直径1.3〜3.0kmの**七つの居住環（Halo）**が貫いて連なり、西の行き止まりは**聖面（Apse）**――巨大な光の円窓を戴く高さ約3kmの壁。その前に**浮遊聖域レンズ**が浮かぶ。稜線と聖面の背には**黒曜の刃**が突き出す（鋭さ20%）。

| 要素 | 内容 |
|---|---|
| 裂け目廊 | 長さ4.6km、幅420〜980m、緩いS字、床は西へ約250m登る（行進路）。中央に発光する水路 |
| 北壁（大壁） | 30段の居住段丘。高さ最大約3.4km。7段ごとに奥行き約100mの公共プラザ段（計4段）。外面は縦リブ＋色帯＋窓帯の貝殻面 |
| 南壁 | 中央区間（t=0.30〜0.82）を意図的に欠落させ、巨大な負空間を作る。代わりに4つの浮遊街区が空に浮かぶ |
| 七環 | R=640〜1480m。それぞれ傾き・位置が異なり、壁に食い込んで固定。内面は発光帯、外面に窓とリブ |
| 聖面（Apse） | 半円の壁。中央は段丘が消えて垂直面になり、半径400mの光円窓を持つ。背面は黒曜の巨大縦リブが外殻を駆け上がり、稜線から棘状に突き出す |
| 浮遊聖域レンズ | R=520mの円盤状。上面は同心の段丘居住街（庭園・パビリオン）、下面は逆さの段丘＋尖塔 |
| 大回廊 Great Hall | 北壁内部（巨大山塊の内側）の屋内公共都市：長さ1.1km、幅460m、尖頭リブ・ヴォールト頂高430m、左右6段の居住ギャラリー、橋、ばら窓 |
| 黒曜の刃 | 高さ520〜2050mの尖った薄板10本（最大は北壁頂部） |

**既存案との区別**：箱の集合・単純岩柱・2塔＋橋・円形競技場・床の上に小建築を並べた模型は構成原理にしていません。《九冠の潮聖堂》の形態（9冠・潮・聖堂）は一切流用していません。ただし自己評価に書いたとおり、**聖面の段丘は競技場的、プラザ視点は「巨大床に小物」的に見える弱点**があります。

```bash

python3 run_views.py 1920 1080 2 ../renders        # 11視点レンダ（ソフトウェア）
python3 make_validation.py ../renders              # GLB書出 + 再パース検証 + validation JSON を ../renders に出力
# Blenderがある環境でのみ（未検証スクリプト）:
blender -b -P blender_build.py -- --out ./blender_out          # .blend + .glb + Blenderレンダ
git push用:  bash ../push_to_github.sh                           # 新規ブランチ claude/c55a-independent-research のみ作成
```
生成は決定論的（seed=7、再生成の geometry SHA-256 一致を確認済み）。座標は m、X東・Y北・Z上（GLBはglTF規約のY-upへ変換して出力）。

## 4. 編集可能性
全パーツが個別メッシュ（例：`N_wall_risers`, `halo3_body_0`, `sanctum_lens_top_ledges`, `apse_rear_fins`）で、GLB上はコレクション名のノード配下に整理。窓・庭・光線は別マテリアルのデカールメッシュ。Blender取込時は自動でZ-upに戻ります。マテリアルはPBR（金属・発光は `KHR_materials_emissive_strength`）。
