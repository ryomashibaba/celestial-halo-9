# HALO-9 M3D-1S/J4 — 実メッシュ公共空間・経路反証監査

**基準：2026-10-24 JST**  
**対象：J3実GLB/OBJの423部品、J3の2公共空洞・11ノード/10辺の経路計画**  
**判定：実バイナリの整合性PASS／2指定小空間の外部表面非交差PASS／4歩行辺に要再設計候補。全空間・全移動の合格ではない。**

## 3. 公共室の実三角形交差

J3の検証は主に直方体オブジェクトのAABB比較だった。今回はOBJ実三角形を使い、各三角形対検査直方体の分離軸定理（13-axis SAT）で、**三角形表面が指定領域を横切るか**を調べた。境界の一致のみを避けるため指定領域を内側へ1mまたは2m縮めている。

| 対象 | 小さな検査用コア | 公共室全包絡（内側2m） |
|---|---|---|
| PUBLIC_VOID_LOWER | 干渉検出0部品 | 交差10部品 |
| PUBLIC_VOID_UPPER | 干渉検出0部品 | 交差7部品 |

下層全包絡の10部品は階段状の段床5、歩行デッキ3、ホール着地点1、採光縁1。上層全包絡の7部品は集会階段床5と歩行デッキ2。

**解釈:** これらの多くは公共空間を作るための意図的な実床・客席で、全室が空っぽでないのは自然。「公共室に10個のバグ」と断定しない。一方で、指定された小さな核心空洞2か所が表面と交差しないことだけでは、公共室全体に使用可能な空間、廊下、高さ、到達性があることは証明できない。対象外メッシュが検査直方体を完全に包囲した場合、表面交差検査では発見できないので、後続の体積内部判定も必要。

## 4. 歩行経路に対する実三角形の局所プローブ

J3の経路のうち徒歩7辺に沿って、各21点（等間隔）へ幅2m×奥行2m×高さ3mの**名目上の頭上空間**を置いて実三角形とSAT交差。意図されたデッキ・公共床・車両などは計算対象から除外した。床支持、斜面、階段、法定通路幅、安全設備を検査したわけではない。

| 徒歩区間 | 干渉検出点 / 21点 | 検出した部品 | 次の再設計 |
|---|---:|---|---|
| LOWER_ENTRY → LOWER_HALL | 0 | — | 実床支持・入口詳細を別検査 |
| **LOWER_HALL → LOWER_TRANSIT** | **1** | `P1_FORUM_RISER_3` | フォーラム段床を横切らない公開回廊の高さ・側方経路を再割当 |
| UPPER_TRANSIT → UPPER_HALL | 0 | — | 実床・接続詳細を別検査 |
| UPPER_HALL → EAST_TRANSIT_LOWER | 0 | — | 実床・接続詳細を別検査 |
| **EAST_TRANSIT_UPPER → EAST_LIVING_CITY** | **1** | `EAST_LIVING_TERRACE_PLAZA` | 公共広場の実面と通過高さ・到着階を区別。意図された着地点なら偽陽性の可能性 |
| **LOWER_HALL → WEST_TRANSIT_LOWER** | **1** | `P1_NORTH_WALL_WEST` | 北側壁の実開口位置と駅までの回廊を整理。壁を無断で除去しない |
| **WEST_TRANSIT_UPPER → WEST_LIVING_CITY** | **2** | `WEST_LIVING_TERRACE_BLDG_1_3_BODY`等 | 住宅外観・公共歩行帯の街区予約を調整。一般建物全棟外観詳細を維持 |

検査結果は「実メッシュ表面が今回の狭い頭上プローブと交差する可能性が検出された」という**修正候補**であり、現実の歩行者で4区間すべてが通行不能と証明したものではない。

また、頭上空間に三角形表面がない4区間も、デッキの連続・支持・昇降機の乗降・各駅の床高さ・斜面・扉・水平軌道の整合性が検証済みではない。

## 5. 優先して修正すべきもの

1. **J4-F01 — 段床にかかる下層中央通路。** 大公室の活動を壊さず通路を通す。床断面・天井・踊り場を実3Dで確認。
2. **J4-F02 — 北側公共室の壁と西駅への回廊の関係。** 入口／非常通路の高さと門型空洞を設計し、駅の接続先まで実デッキを作る。
3. **J4-F03 — 西生活街区への到達と建物の占有。** 住宅棟への侵入で経路を成立させず、街路・公開前室として都市質量に組み込む。
4. **J4-F04 — 東生活街区の広場着地点。** 広場表面の接地は意図的であり得るため、まず経路上の床基準高さを定義してから衝突か否か判定。
5. **J4-F05 — 全室容積の体積包含判定と階段状の公共利用区域。** 小さな検査用コアのみのPASSで全面積完成を主張しない。
6. **J4-F06 — 縦交通の実体検証。** キャビンの図示と連続運転・乗降・公共通路の全区間通行は別。正式本制作に昇格させない。
7. **J4-F07 — 形状美術と10km都市との関係。** 巨大数値と単純な箱の集合に戻らないように、本格造形で生活都市や公共室の内部が外形を生成する必要がある。

## 6. 次の開発ゲート（J5提案）

**次はメッシュ自体を大規模に一括作り直さず、まず下層中央通路・西駅への通路・西生活街区到着の3箇所を、局所的に再配線する「J5・公共動線局所修復」へ進める。**

研究用に版を分け、修正前/後で同じ実三角形のSAT、連続床と頭上クリアランス、影響しないメッシュ部品の保持指紋、全方向の比較を試す。

ただし、**先にAI/Blenderが美術を本当に改善できるかも検証**する必要がある。実3Dを使った美術試作・ユーザー美術審査がREJECTなら、回廊や窓を追加して弱い主形状の延命をしない。
