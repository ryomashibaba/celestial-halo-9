## 1. 今回実際に変更したこと

元J3のGLB/OBJ/J3編集原本とJ4監査結果を、破壊せず別研究ブランチで引き継いだ。

- `LOWER_HALL → LOWER_TRANSIT`：フォーラムの段床、東側の外壁、エレベーター支柱に干渉しないよう、既存の2デッキを**5デッキ**の曲がる回廊へ局所再設計した。
- `LOWER_HALL → WEST_TRANSIT_LOWER`：段床と公共室の開口の間を回る回廊を作り、西エレベーターには支柱間の中央から進入する。既存2デッキを**6デッキ**へ局所再設計した。
- `WEST_TRANSIT_UPPER → WEST_LIVING_CITY`：居住棟の間の公的な隙間を通り抜けるよう、既存1デッキを**3デッキ**へ局所再設計した。
- エレベーター支柱、客席段床、公共室の壁、住宅本体は**削除・移設していない**。
- **J3元モデルの418部品のメッシュと材質は値として一致**。既存5デッキの形状を変更し、新規9デッキを追加した。

## 2. J4で分かったことと、その訂正

J4は経路ノードの**両端を直線で結んで**歩行検査した部分があり、既存デッキの実際の中継点を無視していた。そのため「旧経路のこの部分が必ず壁に衝突している」とは断言できなかった。

J5では、**実際のWALK_DECK部品の区間を一つずつ調べ、全幅を含めた頭上空間**を比較。主にBOX部材を対象とし、屋根や床として意図された役割の一部は別検査へ分けている。

## 3. 改善した数量と限界

**測定方法：** 各デッキの約2m刻みの横断面に、デッキの全幅（20～25m）＋片側0.5m余白、縦断1m余白を設置。デッキの上面（中心線Z＋6m）から0.25m浮かせて高さ3mの頭上空間を確保し、回廊以外の軸整列BOX部材との2D分離軸判定＋Zの重なりを調べた。

| 対象経路 | 旧J3の検出交差イベント | J5の検出交差イベント |
|---|---:|---:|
| LOWER_HALL → LOWER_TRANSIT | 59 | **0** |
| LOWER_HALL → WEST_TRANSIT_LOWER | 65 | **0** |
| WEST_TRANSIT_UPPER → WEST_LIVING_CITY | 57 | **0** |
| **局所修正3経路・計** | **181** | **0** |

「交差イベント」は検査断面×建築BOXの重なりの**検出回数**であり、181個の異なる重大バグを意味しない。

修正対象外の徒歩4経路では、以下が残った。

| 残りの経路 | 検出イベント | 代表的な候補 |
|---|---:|---|
| LOWER_ENTRY → LOWER_HALL | 0 | 名目頭上空間では障害検出なし。ただし通行証明ではない |
| UPPER_TRANSIT → UPPER_HALL | 33 | 上層公共室の客席段床 |
| UPPER_HALL → EAST_TRANSIT_LOWER | 10 | 東側エレベーター支柱・公共室の壁 |
| EAST_TRANSIT_UPPER → EAST_LIVING_CITY | 57 | 東側生活都市の建物外壁・窓 |

**J5後も3経路に合計100件の交差イベント候補**が残っており、全公共経路の実歩行認証には進めない。

### 検査で除外しているもの

段床などは検査対象だが、`shared_floor`、`public_street`、`public_plaza`、`walkable_node_landing`、歩行デッキ自体等、頭上衝突でなく足元の床として意図された部材は暫定的に除外している。**床支持の連続性・端部接合・段差・バリアフリー・勾配・曲がり角での足元の切れ目を確認していない**。

また、この検査は軸整列BOX障害物だけで、`taper`構造、梁同士の三角形干渉、建築母体の体積包含、自由歩行者のコリジョン、移動エレベーター動作は未検査。したがって上の数字だけで「人が実際に歩ける」とは言えない。
